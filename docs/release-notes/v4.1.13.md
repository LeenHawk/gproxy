## v4.1.13

> Updated Claude Code and Codex compatibility, consistent request rewrite rules, and fixes for Android dialogs and image-heavy Claude requests.
>
> 更新 Claude Code 和 Codex 兼容性，修复请求重写规则、Android 弹窗及 Claude 多图请求。

### English

#### Changed

- Align the Claude Code channel with CLI 2.1.316, including User-Agent, billing identity and runtime headers. Preserve validated message IDs and prompt/turn counters that the client supplies for attribution after context compaction.
- Update Codex client identity to 0.166.0 and compatibility with current upstream wire schemas: retain model-owned tool and permission wording, support native literature-search commands, and recognize uploaded audio references in Codex-native message items. These catalog fields do not implement client-side memory or permission policy in the proxy; cross-provider compaction still requires resolved audio content.
- Align Antigravity with the IDE 2.6.0 client and production backend. Remove retired Gemini Flash aliases from model-specific controls.
- Follow the October OpenAI protocol references: preserve model shutdown dates and per-block cache lifetimes in Realtime prompts, and apply GPT-6.1 Terra's reasoning and tool-calling controls.

#### Fixed

- Apply dialect rewrite rules to streaming and token-counting requests, and honor each rule's operation filter when selecting it.
- Scale oversized inline images in Claude requests containing more than 20 image blocks, including images in earlier turns and tool results, to avoid Anthropic's 3000-pixel many-image limit. Bedrock and Vertex also count document blocks toward the threshold.
- Follow Claude Code's current reset-grant eligibility: use the first usable grant of each kind without waiting for the upstream's next-grant pick, and show the upstream's specific reason when a grant cannot be used.
- Fix transparent console dialogs on Android System WebView 108–110 (#307). The console supports WebView 108 and later, and its startup warning appears only below 108.

### 简体中文

#### 调整

- Claude Code 渠道与 CLI 2.1.316 对齐，包括 User-Agent、计费身份和运行时请求头。客户端携带上下文压缩前的消息 ID、prompt/turn 计数时，按其规则校验并保留，用于压缩后的请求归因。
- Codex 客户端身份更新至 0.166.0，并兼容当前上游 wire 结构：保留模型目录中的工具和权限提示文本，支持原生论文检索命令，识别 Codex 原生消息中的已上传音频引用。这些目录字段不会让代理执行客户端的记忆或权限策略；跨供应商压缩音频仍须先取得实际内容。
- Antigravity 与 IDE 2.6.0 客户端及生产后端对齐；移除 Gemini 模型控制中已退役的 Flash 别名。
- 跟进 OpenAI 十月协议参考：保留模型停用日期和 Realtime prompt 的块级缓存时长，并应用 GPT-6.1 Terra 的推理强度与工具调用规则。

#### 修复

- 方言重写规则现可应用于流式和 token 计数请求，规则选择会遵守各自的操作过滤条件。
- Claude 请求包含超过 20 个图像块时，自动缩小超尺寸的内嵌图片，避免触发 Anthropic 多图请求的 3000 像素边长限制；历史轮次和工具结果中的图片也纳入处理，Bedrock、Vertex 同时将文档块计入阈值。
- Claude Code 重置卡跟随当前上游规则：每种类型的第一张可用重置卡均可兑换，不再等待上游指定的下一张；不可用时显示上游给出的具体原因。
- 修复 Android System WebView 108–110 上控制台弹窗背景透明、与页面内容重叠的问题（#307）。控制台支持 WebView 108 及以上版本，启动提示仅在低于 108 时出现。
