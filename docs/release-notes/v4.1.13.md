## v4.1.13

> The console works on Android System WebView 108.
>
> 控制台支持 Android System WebView 108。

### English

#### Changed

- Align the Claude Code channel with CLI 2.1.311, including User-Agent, billing identity and runtime headers.
- Claude Code reset grants follow CLI 2.1.311: grants no longer wait for the upstream's next-grant pick; the first usable grant of each kind (session, weekly, Fable or full) can be redeemed, and the console shows the upstream's specific reason when a grant is unavailable, such as a blocking 5-hour or weekly limit.

#### Fixed

- Fix the console in the Android app drawing transparent dialogs over the page on Android System WebView 108 to 110, which some devices without Google Play cannot update (#307). The console now supports WebView 108 and later, and the startup warning appears only below 108.

### 简体中文

#### 调整

- Claude Code 渠道与 CLI 2.1.311 对齐，包括 User-Agent、计费身份和运行时请求头。
- Claude Code 重置卡与 CLI 2.1.311 保持一致：不再等待上游指定的下一张，每种类型（5 小时、每周、Fable 或全部）的第一张可用重置卡均可兑换；重置卡不可用时，控制台显示上游给出的具体原因，例如被 5 小时或每周额度阻塞。

#### 修复

- 修复 Android App 在 Android System WebView 108 至 110 上控制台弹窗背景透明、与页面内容重叠的问题；部分没有 Google Play 的设备无法更新 WebView（#307）。控制台现已支持 WebView 108 及以上版本，启动提示仅在低于 108 时出现。
