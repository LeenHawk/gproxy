# GPROXY 4.0.2

> Better keyboard and screen-reader access, application startup controls, and reliable SQLite file paths.

## English

### Added

- Application settings for launch at login, starting minimized, and closing to the system tray. The setup wizard also offers these choices, and tray menus follow the selected language.
- HarmonyOS controls for startup and background operation, with permission status and guidance in the application.
- Separate Microsoft Store packaging identities for Desktop and CLI, release-specific Store notes, and WinGet submission manifests.
- An update-signature verification setting in the console and CLI. Verification is enabled by default; disabling it still keeps package size and SHA-256 checks.

### Fixed

- Improve keyboard navigation, visible focus, dialog focus restoration, and skip navigation. Form labels, validation messages, status announcements, and quota-chart summaries are more accessible to screen readers.
- Improve text and control contrast, touch targets, narrow-screen layouts, and reduced-motion behavior. Enable application zoom, including Android pinch zoom.
- Pass SQLite filenames directly to the database driver so Windows paths and filenames containing URL characters open correctly. The fix also covers the SDK and v3 database migration.
- Keep Microsoft Store package preparation independent of publication credentials.
- Fix ArkTS error types in the HarmonyOS tray code so the HAP package compiles.
- Declare English, Simplified Chinese and Traditional Chinese support in Windows MSIX packages, matching the console and Store listing languages.

### Changed

- Update hosted deployment templates to use the prebuilt v4.0.2 packages.
- Accessibility changes were checked with browser automation, Linux desktop accessibility tools, and an Android emulator. This release does not claim full WCAG AA certification or completed Windows/macOS screen-reader acceptance testing.

## 简体中文

### 新增

- Application 新增登录系统时启动、启动后最小化、关闭窗口时保留托盘等设置，首次启动向导也可配置。托盘菜单跟随所选语言。
- HarmonyOS 新增自启动和后台运行设置，并在应用中显示权限状态和操作指引。
- Desktop 和 CLI 使用独立的 Microsoft Store 打包标识，商店更新说明按版本生成，并提供 WinGet 提交清单。
- 控制台和 CLI 新增更新签名校验设置，默认开启；关闭后仍校验安装包大小和 SHA-256。

### 修复

- 改善键盘导航、焦点可见性、关闭弹窗后的焦点恢复和跳转主内容操作。补全表单标签、校验提示、状态播报和配额图表摘要，方便读屏使用。
- 改善文字与控件对比度、触控目标、窄屏布局和减少动画设置，启用应用缩放及 Android 双指缩放。
- SQLite 文件名直接传给数据库驱动，修复 Windows 路径和含 URL 特殊字符的文件名无法正确打开的问题，同时覆盖 SDK 和 v3 数据库迁移。
- Microsoft Store 打包准备不再依赖发布凭证。
- 修复 HarmonyOS 托盘代码的 ArkTS 异常类型，使 HAP 可以正常编译。
- Windows MSIX 包补齐英语、简体中文和繁体中文声明，与控制台和商店文案的语言保持一致。

### 调整

- 托管部署模板更新为使用 v4.0.2 预编译包。
- 无障碍改动已通过浏览器自动化、Linux 桌面无障碍工具和 Android 模拟器检查；本版不宣称完整 WCAG AA 认证，也不代表已完成 Windows/macOS 读屏验收。
