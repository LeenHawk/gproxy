## v2.6.2

> Adds an opt-in DeepSeek beta Chat Completions route for assistant prefix completion while keeping stable endpoints as the default.

### English

#### Added

- **DeepSeek prefix completion.** DeepSeek providers now expose an `enable_beta` switch in the Console and `settings_json`. When enabled, OpenAI Chat Completions requests use `/beta/chat/completions`, allowing the final assistant message to carry `"prefix": true`. The switch affects only Chat Completions; Responses, model, and Anthropic-compatible routes remain on their stable endpoints, and exact endpoint overrides still take precedence.

### 简体中文

#### 新增

- **DeepSeek 预填充续写。** DeepSeek provider 现可在控制台或 `settings_json` 中开启 `enable_beta`。开启后，OpenAI Chat Completions 请求会使用 `/beta/chat/completions`，允许最后一条 assistant 消息携带 `"prefix": true`。该开关仅影响 Chat Completions；Responses、模型和 Anthropic-compatible 路由仍使用正式端点，精确 endpoint 配置仍具有最高优先级。
