# GPROXY v4 development builds

Development snapshots from the `dev` branch are published under the rolling
`nightly` release. Asset names stay stable; each successful publication replaces the previous artifact set.
The signed update manifest records the source commit SHA and package checksums.
Individual checksum and provenance sidecars are not attached to development releases.

- Tauri application installers: Linux DEB, macOS DMG, Windows MSIX, and signed
  Android APK, each for x86_64 and ARM64.
- Server portable archives, Cloudflare Workers bundles, and GNU/musl container
  images remain separate deployment options.
- Tauri Android APKs have their own entries in the signed update manifest.

Windows MSIX files use the Microsoft Store identity and are unsigned submission
packages. Install the Store-distributed application for a trusted signed package.
macOS bundles use ad-hoc signing and are not notarized. These are development
builds, not a stable release.
