## v2.5.0

> Adds four upstream channels, streamlines the Console dashboard, and delivers a responsive credential-usage workspace without horizontal scrolling.

### English

#### Added

- **More upstream channels.** Native channel support is now available for Cloudflare AI Gateway, xAI, Alibaba Qwen, and WorkBuddy, including channel metadata and Console configuration where applicable.

#### Changed

- **Responsive credential usage.** The credential-usage dialog now uses a wider desktop workspace, a fixed desktop table, and dedicated cards below the desktop breakpoint. Quota-cycle fields and model breakdowns remain readable without a horizontal scrollbar, and modal scrolling uses a compact theme-aware style.
- **Simpler dashboard overview.** The Console home dashboard removes low-value local anomaly, breaker-detail, and recent-usage sections so the overview stays focused on actionable operational information.
- **Clearer provider configuration.** Channel names and credential inputs are easier to distinguish when configuring the newly supported providers.
- **Request compatibility.** Codex stream options are passed through without unnecessary filtering.

### 简体中文

#### 新增

- **更多上游渠道。** 新增 Cloudflare AI Gateway、xAI、阿里云通义千问和 WorkBuddy 原生渠道支持，并提供相应的渠道元数据及 Console 配置能力。

#### 变更

- **响应式凭证用量。** 凭证用量弹窗在桌面端采用更宽的工作区和固定表格，在较窄屏幕改用专用周期卡片；额度周期字段与模型明细无需横向滚动即可完整阅读，同时加入紧凑且跟随主题的滚动条样式。
- **更精简的首页仪表盘。** Console 首页移除了价值较低的局部异常、熔断器详情和最近用量区块，让概览聚焦于可操作的运行信息。
- **更清晰的供应商配置。** 配置新渠道时，渠道名称与凭证输入项更容易识别。
- **请求兼容性。** Codex 流式选项现在会直接透传，不再进行不必要的过滤。
