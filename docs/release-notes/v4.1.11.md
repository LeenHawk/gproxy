## v4.1.11

> The Microsoft Store CLI starts without administrator rights.
>
> Microsoft Store 版 CLI 无需管理员权限即可启动。

### English

#### Fixed

- Fix the Microsoft Store (MSIX) CLI crashing on launch without administrator rights. A Start menu launch runs in `System32`, where the default `./data` directory could only be created elevated.

#### Changed

- The Microsoft Store (MSIX) CLI now defaults its data directory to `%LOCALAPPDATA%\GPROXY` when `--data-dir` / `GPROXY_DATA_DIR` is not set. If you previously ran `gproxy` from a terminal and kept data in that directory's `data` folder, pass `--data-dir <that folder>` or move its contents to `%LOCALAPPDATA%\GPROXY`. Portable ZIP, Linux, macOS and container installs still default to `./data`.

### 简体中文

#### 修复

- 修复 Microsoft Store（MSIX）版 CLI 在没有管理员权限时启动即崩溃的问题。从开始菜单启动时工作目录是 `System32`，默认的 `./data` 目录只有提权后才能创建。

#### 调整

- Microsoft Store（MSIX）版 CLI 在未设置 `--data-dir` / `GPROXY_DATA_DIR` 时，默认数据目录改为 `%LOCALAPPDATA%\GPROXY`。如果你之前在终端里某个目录下运行 `gproxy`，数据保存在该目录的 `data` 文件夹中，请通过 `--data-dir <该文件夹>` 指定，或将其内容移动到 `%LOCALAPPDATA%\GPROXY`。便携 ZIP、Linux、macOS 和容器安装仍默认使用 `./data`。
