## v2.1.5

> Hardens Claude Code OAuth token rotation across native and edge deployments, restores retryable login completion, broadens Claude fallback support, and fixes macOS packaging.

### English

#### Fixed

- **Claude Code OAuth compatibility.** Authorization-code exchange, cookie exchange, and refresh now consistently use the Anthropic API form token endpoint with the five inference-account scopes. Granted project scopes are preserved, `invalid_scope` retries with the original grant, and permanent `invalid_grant` responses are identified explicitly.
- **Cross-instance token rotation.** Redis, Upstash, and libSQL now use owner-scoped renewable leases around refresh-token rotation and sealed-secret compare-and-swap persistence. Contending instances adopt the winner's token instead of double-spending a rotating refresh token, while cache outages remain transient rather than cooling a healthy credential.
- **Retryable OAuth completion.** Invalid pasted callbacks and transient exchange failures no longer consume the pending PKCE login session. The session is cleared only after a successful code exchange.
- **macOS DMG contents.** The packaged application now includes the server binary required by the launcher.

#### Changed

- **Claude fallback coverage.** Supported Claude API-like channels can apply configured fallback routing to every eligible model rather than only Fable requests; unsupported platforms remain excluded.
- **OAuth refresh timing.** Claude Code access tokens follow the official five-minute proactive refresh window, and token requests use a 30-second deadline.
- **Console dependencies.** Frontend dependencies receive routine compatibility and security updates.

### 简体中文

#### 修复

- **Claude Code OAuth 兼容性。** Authorization Code Exchange、Cookie Exchange 与 Refresh 统一使用 Anthropic API 的 Form Token Endpoint和五项推理账号 Scope；已有 Project Scope会继续保留，`invalid_scope` 会使用原始授权范围重试，并明确识别永久性的 `invalid_grant`。
- **跨实例 Token 轮换。** Redis、Upstash 与 libSQL 现在以带 Owner 的可续期 Lease保护 Refresh Token轮换及 Sealed Secret CAS写入；竞争实例会采用胜出实例的新 Token，不再重复消耗轮换型 Refresh Token，Cache故障也只作为 Transient处理而不会冷却健康凭据。
- **可重试 OAuth 完成流程。** 无效的 Callback粘贴与临时 Exchange失败不再提前消费待完成的 PKCE Login Session；仅在 Code Exchange成功后清理 Session。
- **macOS DMG 内容。** 应用安装包现在包含 Launcher所需的 Server Binary。

#### 调整

- **Claude Fallback 覆盖范围。** 支持的 Claude API 类渠道可对所有符合条件的模型应用已配置的 Fallback Routing，而不再仅限 Fable请求；不支持的平台仍会排除。
- **OAuth Refresh 时机。** Claude Code Access Token改为遵循官方的到期前五分钟主动 Refresh窗口，Token请求使用 30 秒 Deadline。
- **Console 依赖。** 更新前端兼容性与安全维护依赖。
