## v2.5.1

> Improves upstream model synchronization by enriching existing model metadata and optionally applying provider-scoped prices from the bundled default table.

### English

#### Fixed

- **Existing model enrichment.** Pulling models can now fill missing display names, context and token limits, and thinking capabilities on already-persisted models instead of limiting the operation to new model IDs.

#### Changed

- **Safe additive synchronization.** Existing manual metadata, enabled state, and variants are preserved; upstream values only fill empty fields.
- **Optional default pricing.** The pull dialog can match the bundled default price table and create exact rules scoped to the current provider without overwriting existing exact rules.
- **Clearer pull preview.** The Console identifies models with available metadata or default prices and reports separate counts for added, enriched, and priced models.

### 简体中文

#### 修复

- **补全已有模型。** 拉取模型时，现在可以为已持久化模型补充缺失的显示名、上下文与 Token 限制及推理能力，不再仅能导入新的模型 ID。

#### 变更

- **安全的增量同步。** 保留已有的人工元数据、启用状态和变体配置；上游值只填充空字段。
- **可选默认价格。** 拉取弹窗可匹配内置默认价格表，并为当前供应商创建精确价格规则，且不会覆盖已有精确规则。
- **更清晰的拉取预览。** Console 会标识可补充元数据或默认价格的模型，并分别汇报新增、补全和定价数量。
