## v4.1.3

### English

v4.1.2 was published only as crates.io libraries; its application packages were not released. This release includes all v4.1.2 changes.

- Build Android distributions in six parallel channel/ABI jobs and assemble universal store packages without recompiling Rust. Reuse validated UPX outputs instead of stripping them again.
- Fix x86_64 Android packages, which failed to start in v4.1.1: UPX left an out-of-range section header table and lowered native library alignment to 4 KiB. A patched UPX keeps compression, valid section headers and 16 KiB alignment.
- Add Headless Windows MSIX packages with the separate `gproxy-headless` command and WinGet submission metadata.

- Rename the application identifier to `com.leenhawk.gproxy.desktop` across desktop, Android and HarmonyOS. Android treats this as a separate application from the former `.app` package.

- Refresh upstream model candidates before serving model lists and details from the local catalog. Preserve configured names, disabled models and permission filtering.
- Preserve team and organization permissions when importing v3 configurations.
- Update Claude Code and Codex compatibility, add Claude Files and MCP services, and support OpenAI Decisions requests.
- Fetch image and file references that the target protocol cannot read before cross-protocol conversion, instead of dropping them; a failed fetch now fails the request. Send image data in Chat and Responses file parts to Claude as image blocks.
- Return errors instead of panicking on malformed Gemini video and fan-out requests, and keep unknown extension fields out of converted Claude thinking settings.
- Record time to first token and show generation throughput; add body and header rewrite conditions, including JMESPath expressions.
- Bundle Console fonts and make optional native font downloads explicit. Keep mobile privacy notices informational.
- Fix vulnerable transitive CSS parsing and Cloudflare image-processing dependencies.
- Attempt production Windows signing with SignPath; retain unsigned packages when signing is unavailable or verification fails.
- Repair macOS DMG filesystem allocation and retain reproducible Android packaging with the existing APK signing certificate.
- Update Android version code to 4001003. Stable releases continue to include the signed F-Droid reference APK; F-Droid publication follows its own review and build process.

### 简体中文

v4.1.2 仅发布了 crates.io 库，未发布应用安装包；本版本包含 v4.1.2 的全部变更。

- Android 按渠道和架构拆为六个并行构建任务，通用商店包复用原生库完成打包；已验证的 UPX 产物不再重复 strip。
- 修复 v4.1.1 中无法启动的 x86_64 Android 包：UPX 留下越界的段表，并把原生库对齐降为 4 KiB。改用打过补丁的 UPX，保留压缩，同时保证段表有效和 16 KiB 对齐。
- 增加 Headless Windows MSIX，使用独立的 `gproxy-headless` 命令，并接入 WinGet 清单生成与提交流程。

- 桌面、Android 和鸿蒙的应用标识统一改为 `com.leenhawk.gproxy.desktop`；Android 会将其视为与原 `.app` 包分开的新应用。

- 查询模型列表或详情时，按开关刷新上游候选并合并到本地，再按本地配置返回；保留暴露名称、禁用状态和权限过滤。
- 导入 v3 配置时保留团队和组织权限。
- 更新 Claude Code 和 Codex 兼容性，增加 Claude Files、MCP 服务与 OpenAI Decisions 请求支持。
- 跨协议转换前，先获取目标协议无法直接读取的图片和文件引用，不再静默丢弃；获取失败时请求返回错误。Chat 与 Responses 文件部件中的图片数据改为以图片块发送给 Claude。
- 畸形的 Gemini 视频和扇出请求改为返回错误，不再 panic；转换后的 Claude thinking 配置不再带入未知扩展字段。
- 记录首 token 时间并展示生成吞吐量；增加请求体和请求头改写条件，支持 JMESPath 表达式。
- Console 内置字体，原生端额外字体下载改为主动选择；移动端隐私说明不再阻断使用。
- 更新文档站 CSS 解析和 Cloudflare 图像处理的间接依赖，修复已报告的依赖安全问题。
- Windows 发布包尝试通过 SignPath 正式签名；签名服务不可用或验证失败时继续发布原来的未签名包。
- 修复 macOS DMG 文件系统空间分配，Android 继续使用可复现打包与原 APK 签名证书。
- Android 版本代码更新为 4001003；稳定版继续提供签名 F-Droid 参考 APK，F-Droid 上架由其审核和构建流程决定。
