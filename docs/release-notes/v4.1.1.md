## v4.1.1

### English

- Make release builds reproducible with fixed build paths, pinned Android tools and source-derived timestamps.
- Normalize macOS HFS images, Windows MSIX ZIP dates, Android R8 metadata, HarmonyOS archives and Linux packages.
- Add a separately signed F-Droid APK to stable releases using the existing upstream signing certificate, with signature-copy verification.
- Repair F-Droid build dependencies and CI artifact handling; refresh frontend, documentation and Rust dependencies.
- Update Android version code to 4001001. F-Droid inclusion remains subject to maintainer review.

### 简体中文

- 固定构建路径、Android 工具版本和源码时间戳，支持可复现的发布构建。
- 统一 macOS HFS 镜像、Windows MSIX ZIP 时间、Android R8 元数据、鸿蒙归档和 Linux 软件包中的不稳定信息。
- 正式发布增加独立的 F-Droid APK，沿用上游签名证书并验证签名复制。
- 修复 F-Droid 构建依赖和 CI 产物处理，更新前端、文档和 Rust 依赖。
- Android 版本代码更新为 4001001；F-Droid 收录仍需维护者审核。
