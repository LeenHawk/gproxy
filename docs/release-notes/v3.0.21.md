## v3.0.21

> Support PostgreSQL TLS and improve SQL connection diagnostics and model variant discovery.
> 支持 PostgreSQL TLS，完善 SQL 连接错误诊断及模型变体发现。

### English

#### Fixed

- Connect to TLS-required PostgreSQL services such as Neon using `sslmode=require`, with certificate and hostname verification against bundled Mozilla roots.
- Preserve underlying PostgreSQL and MySQL connection failure details instead of returning a generic connection error. Invalid MySQL option values are omitted from diagnostics.
- Include configured provider model variants in aggregated and ordinary provider-scoped model lists, retaining base model metadata and honoring `expose_base` in the stored provider catalogue.

#### Changed

- Document PostgreSQL `sslmode=require` and MySQL `require_ssl=true` for encrypted database connections. MySQL retains certificate and hostname verification by default when TLS is enabled.

### 简体中文

#### 修复

- 支持通过 `sslmode=require` 连接 Neon 等要求 TLS 的 PostgreSQL 服务，使用内置 Mozilla 根证书校验证书及主机名。
- PostgreSQL 和 MySQL 连接失败时保留底层错误原因，不再只显示通用连接错误；MySQL 配置错误不会输出无效参数的值。
- 聚合入口和普通供应商入口的模型列表包含已配置的供应商模型变体，继承基础模型元数据，并在存储供应商目录中遵守 `expose_base`。

#### 变更

- 补充 PostgreSQL `sslmode=require` 和 MySQL `require_ssl=true` 加密连接说明。MySQL 启用 TLS 后默认仍校验证书及主机名。
