## v2.0.15

> Adds synthetic streaming for buffered upstreams and 30-minute cache-write billing, improves routing controls, and publishes the v2 protocol crate on crates.io.

### English

#### Added

- **Synthetic streaming from buffered upstreams.** Routing rules can now map an inbound `stream_generate_content` request to a non-streaming `generate_content` upstream, then synthesize the expected OpenAI Chat Completions, OpenAI Responses, Claude Messages, or Gemini stream on the way back. Native servers emit protocol-appropriate keepalives while waiting for the buffered response.
- **30-minute cache-write pricing.** Pricing rules, persistence backends, migrations, billing, usage records, and the Console now support `cache_creation_30m_price` and 30-minute cache-creation token counts. OpenAI Chat Completions and Responses `cache_write_tokens` are separated from normal input tokens and charged at this rate.
- **Public v2 protocol crate.** `gproxy-protocol` `2.0.15` is now packaged with crates.io metadata and documentation and published for downstream Rust consumers.

#### Fixed

- **Route circuit-breaker editing.** The Console no longer requires operators to edit raw route settings JSON. Dedicated controls now cover consecutive failures, cooldown, error-rate windows, thresholds, and minimum request counts while preserving unrelated settings.
- **Duplicate release workflows.** Main-branch and tag pushes for the same commit now share SHA-based concurrency, so the tag build replaces the redundant staging run instead of racing to update the deploy branch.

#### Changed

- **Routing-rule destination controls.** The routing matrix now exposes both destination operation and destination protocol for `transform_to` rules, making streaming-to-buffered routing configurable from the Console and visible in behavior badges.
- **Cache usage reporting.** Usage pages and API records now display 5-minute, 30-minute, and 1-hour cache-creation tokens separately, and bundled OpenRouter pricing data includes the new cache-write rate.

### 简体中文

#### 新增

- **从非流式上游合成流。** Routing rule 现在可以把入站 `stream_generate_content` 请求映射到非流式 `generate_content` 上游，再将完整响应合成为客户端期望的 OpenAI Chat Completions、OpenAI Responses、Claude Messages 或 Gemini 流。Native server 在等待完整响应期间会发送符合对应协议的 keepalive。
- **30 分钟缓存写入计价。** Pricing rule、各持久化后端、migration、billing、usage record 和 Console 现在支持 `cache_creation_30m_price` 及 30 分钟 cache creation token。OpenAI Chat Completions 与 Responses 的 `cache_write_tokens` 会从普通 input token 中拆分，并按该价格计费。
- **公开 v2 protocol crate。** `gproxy-protocol` `2.0.15` 已补齐 crates.io 元数据与文档，并发布给下游 Rust 项目使用。

#### 修复

- **Route 熔断设置编辑。** Console 不再要求管理员直接编辑 route settings JSON；现在可通过独立控件设置连续失败次数、冷却时间、错误率窗口、阈值和最小请求数，同时保留其它已有设置。
- **重复 release workflow。** 同一 commit 的 main push 与 tag push 现在共用基于 SHA 的 concurrency；tag build 会替换重复的 staging run，避免两者竞争更新 deploy branch。

#### 调整

- **Routing rule 目标控件。** Routing matrix 的 `transform_to` rule 现在同时提供目标 operation 和目标 protocol 选择，既可在 Console 配置流式到非流式的路由，也会在 behavior badge 中明确显示目标。
- **缓存用量展示。** Usage 页面与 API record 现在分别展示 5 分钟、30 分钟和 1 小时 cache creation token；内置 OpenRouter pricing data 也包含新的 cache-write 价格。
