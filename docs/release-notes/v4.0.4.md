# GPROXY 4.0.4

> Add GLM, MiniMax and Devin capabilities, reduce mobile downloads, and improve OAuth, Responses compatibility and usage totals.

## English

### Added

- GLM/Z.ai API and Coding Plan channels, including their separate endpoints, model catalogs and subscription quota queries.
- MiniMax API and subscription support, including text, quota queries and H3 video operations.
- Devin OAuth login and native CLI tool support.
- Batch model selection in the Console catalog, and a restored top-level About entry.
- Headless CLI packages across native platforms, additional hosted deployment templates, and WebSocket support on Vercel and Deno.

### Fixed

- Accept Responses history items without IDs and avoid putting credentials on cooldown for local request errors.
- Compute default usage aggregates over the full requested range instead of a limited first page.
- Support dynamic HTTP loopback ports for OAuth callbacks and supply default hints for Devin OAuth endpoint settings.
- Normalize legacy quota and tier decimal values during migration.
- Enable effective fat LTO for mobile shared libraries and remove release optimization downgrades across build paths.
- Harden credential ownership, OAuth scopes, resource authorization, remote fetching, and upstream credential isolation.
- Repair musl and Serverless builds, HarmonyOS packaging and startup, and v3 cached-token usage migration.
- Remove the redundant beta release alias and refresh rolling release titles while keeping staging and nightly separate.

### Changed

- Reduce Android download size with native-library stripping, UPX and ZIP compression before signing. Fonts now download on demand and are cached locally; license notices and the updated privacy notice remain available offline.
- Apply native-library compression to HarmonyOS packaging and restore maximum compression for Serverless and Windows ARM64 cross builds.
- Build Android CLI packages with the official Termux toolchain and keep Termux updates under its package manager.
- Automatically submit stable releases to F-Droid and submit Microsoft-signed MSIX packages to WinGet after Store synchronization.
- Update hosted deployment templates to v4.0.4 and the mobile store version code to 4000004.

## 简体中文

### 新增

- 新增 GLM/Z.ai API 与 Coding Plan 渠道，分别提供端点、模型目录和订阅额度查询。
- 新增 MiniMax API 与订阅支持，涵盖文本、额度查询和 H3 视频操作。
- 新增 Devin OAuth 登录与原生 CLI 工具支持。
- 控制台模型目录支持批量选择，恢复顶层“关于”入口。
- 为原生平台提供无界面 CLI 包，增加托管部署模板，并支持 Vercel 和 Deno 上的 WebSocket。

### 修复

- 接受不含 ID 的 Responses 历史项，本地请求错误不再导致凭据进入冷却。
- 默认用量聚合统计覆盖完整请求范围，不再只计算受限的第一页。
- OAuth 回调支持动态 HTTP 回环端口，补齐 Devin OAuth 端点配置的默认提示。
- 迁移时规范化旧版额度和层级的小数值。
- 让移动端共享库实际启用完整 LTO，并移除各构建路径中降低发布优化等级的配置。
- 加强凭据归属、OAuth 权限范围、资源授权、远程抓取与上游凭据隔离。
- 修复 musl、Serverless 构建，鸿蒙打包与启动，以及 v3 缓存令牌用量迁移。
- 移除多余的 beta 发布别名，更新滚动发布标题，保持 staging 与 nightly 独立。

### 调整

- 在签名前对 Android 原生库去除调试数据并使用 UPX、ZIP 压缩，缩小下载体积。字体改为按需下载并本地缓存，许可证和更新后的隐私说明仍可离线查看。
- 鸿蒙打包接入原生库压缩，Serverless 与 Windows ARM64 交叉构建恢复最大压缩等级。
- Android CLI 使用官方 Termux 工具链打包，Termux 安装由包管理器负责更新。
- 稳定版发布后自动提交 F-Droid；Microsoft Store 同步签名 MSIX 后再提交 WinGet。
- 托管部署模板更新至 v4.0.4，移动端商店版本号更新为 4000004。
