## v2.1.1

> Adds native Microsoft Foundry/Azure OpenAI and Amazon Bedrock channels, safer first-boot administration, stronger observability controls, and broader protocol and network compatibility.

### English

#### Added

- **Microsoft Foundry and Azure OpenAI channel.** The new `azure` channel supports OpenAI v1 and Claude-compatible requests, embeddings, compaction, and deployment-bound image generation and editing. Exact endpoints and `{model}` deployment placeholders are supported for Azure routing.
- **Amazon Bedrock channel.** The new `aws-bedrock` channel uses Bedrock bearer tokens and native Converse/ConverseStream APIs for chat, responses, Claude, Gemini, tool calls, image and document inputs, streaming, token counting, cache points, and compaction. Region-derived control-plane and runtime endpoints default to `us-east-1`.
- **Safer first-boot administration.** A fresh native installation now generates both a random administrator password and an `sk-...` administrator API key when neither bootstrap credential is configured. These credentials are printed only on first startup.
- **Observability controls.** Usage Explorer can filter by credential, while Usage, request logs, and audit logs each provide a confirmed clear-all action.
- **Optional SQLite size limit.** Native SQLite deployments can configure `max_database_size_mb`. The retention task removes the oldest request and audit logs and vacuums the database toward the configured limit without deleting usage or control-plane data.

#### Fixed

- **Subscription credential cooldowns.** Codex and Claude Code now cool down the entire credential when account-wide quota or authentication failures occur, avoiding repeated requests against the same exhausted or invalid account while preserving model-scoped handling for independent limits.
- **Provider and transform compatibility.** Gemini tool schema types are normalized recursively for Claude, OpenAI Compact can route to OpenAI Responses, and cross-protocol PDF, text, URL, and non-image attachment conversions preserve more source information.
- **Variant editing.** The Console restores existing behavior presets when editing model variants and preserves custom rewrite actions that cannot be represented by a preset.
- **Proxy and login input compatibility.** Native proxy configuration accepts vendor-style `host:port:user:pass` URLs, and the ChatGPT login form correctly accepts either a cookie value or a complete `Cookie:` header.
- **Sensitive header redaction.** Captured JSON payloads now redact secrets inside embedded name/value header objects, including authorization, cookie, and API-key headers.

#### Changed

- **Protocol-specific magic cache settings.** The previous `enable_magic_cache` setting is split into `enable_openai_magic_cache` and `enable_claude_magic_cache`, allowing each target protocol to be controlled independently. Existing database settings are migrated automatically.
- **Dual-stack connectivity test.** Proxy connectivity checks now probe IPv4 and IPv6 in parallel and display each result independently. The Admin API response now returns nested `ipv4` and `ipv6` probe objects instead of the previous top-level IP fields.
- **Consistent streaming responses.** Successfully decoded streaming responses now consistently use `text/event-stream`, including streams received from binary upstream transports such as AWS EventStream.

### 简体中文

#### 新增

- **Microsoft Foundry 与 Azure OpenAI Channel。** 新增 `azure` Channel，支持 OpenAI v1 与 Claude 兼容请求、Embedding、Compact，以及绑定 Deployment 的图片生成和编辑；Azure 路由可使用精确 Endpoint 与 `{model}` Deployment 占位符。
- **Amazon Bedrock Channel。** 新增 `aws-bedrock` Channel，使用 Bedrock Bearer Token 和原生 Converse/ConverseStream API，支持 Chat、Responses、Claude、Gemini、Tool Call、图片与文档输入、流式响应、Token 计数、缓存点和 Compact。按 Region 生成控制面与 Runtime Endpoint，默认 Region 为 `us-east-1`。
- **更安全的首次启动管理凭据。** 全新 Native 安装在未配置 Bootstrap 凭据时，会同时生成随机管理员密码和 `sk-...` 管理员 API Key，并且只在首次启动时输出。
- **可观测性管理能力。** Usage Explorer 新增按 Credential 筛选；Usage、请求日志和审计日志均新增带确认步骤的全部清空操作。
- **可选 SQLite 大小限制。** Native SQLite 部署可配置 `max_database_size_mb`。保留任务会删除最旧的请求日志与审计日志，并执行 Vacuum 使数据库接近目标上限，不会删除 Usage 或控制面数据。

#### 修复

- **订阅 Credential 冷却。** Codex 和 Claude Code 遇到账号级额度或认证错误时会冷却整个 Credential，避免对同一已耗尽或失效账号反复请求；具有独立额度的模型仍保持模型级处理。
- **Provider 与 Transform 兼容性。** Gemini Tool Schema 类型会递归规范化以兼容 Claude；OpenAI Compact 可路由到 OpenAI Responses；跨协议转换可更完整地保留 PDF、文本、URL 和非图片附件信息。
- **Variant 编辑。** Console 编辑模型 Variant 时会恢复已有行为预设，并保留无法由预设表达的自定义 Rewrite Action。
- **代理与登录输入兼容性。** Native 代理配置支持供应商常见的 `host:port:user:pass` URL；ChatGPT 登录表单可正确接受 Cookie 值或完整的 `Cookie:` Header。
- **敏感 Header 脱敏。** 捕获的 JSON Payload 现在会遮蔽嵌入式 name/value Header 对象中的 Authorization、Cookie 和 API Key 等敏感值。

#### 调整

- **按协议拆分魔法缓存设置。** 原 `enable_magic_cache` 拆分为 `enable_openai_magic_cache` 与 `enable_claude_magic_cache`，可独立控制两个目标协议；已有数据库设置会自动迁移。
- **双栈连通性测试。** 代理连通性测试会并行探测 IPv4 与 IPv6，并分别展示结果。Admin API 响应改为嵌套的 `ipv4` 与 `ipv6` Probe 对象，不再返回原顶层 IP 字段。
- **统一流式响应。** 成功解码后的流式响应统一使用 `text/event-stream`，包括从 AWS EventStream 等二进制上游传输解码得到的流。
