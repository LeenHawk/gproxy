## v4.1.7

> Provider-name model routing, Vertex region overrides, Devin model discovery, and faster streaming conversions.
>
> 模型前缀只按供应商名解析，新增 Vertex 区域覆盖与 Devin 模型发现，流式转换更及时。

### English

#### Breaking

- A model prefix now always names a provider. The `channel/model` form is removed: `codex/gpt-5` reaches the provider named `codex`, not every provider on the `codex` channel. Use a model route to balance across providers. This fixes provider mounts such as `/openai/v1` failing with `no_usable_target` when the provider's name matched a different channel.

#### Added

- Support Vertex region overrides per provider and per credential.
- Discover Devin models live and replay signed reasoning.
- Display access and refresh token expirations for credentials.
- Support Gemini continuation fields and Gemini 4 Argon thinking controls.
- Publish `llms.txt`, `llms-full.txt` and `llms-small.txt` for the documentation.

#### Fixed

- Emit converted Responses streams as events arrive instead of waiting for completion.
- Include PostgreSQL and MySQL drivers in CLI release builds.
- Align Claude Code direct OAuth identity with CLI 2.1.299.
- Omit unsupported reasoning content from Codex requests.
- Aggregate and normalize Vertex publisher model catalogs.
- Preserve upstream model identities without implicit aliases.
- Preserve slashes in provider-scoped model names.
- Enforce channel-specific credential types in the Console.
- Display saved model prices consistently.

#### Changed

- Publish Docker Hub images as `gproxy2/gproxy`; the documentation lists the Docker Hub, GitHub, GitLab and CNB registries.
- Build container images from Docker Hub bases with UPX-packed binaries.
- Refresh Rust, Console, and documentation dependencies.
- Update Android version code to 4001007.

### 简体中文

#### 不兼容变更

- 模型前缀现在只表示供应商名，移除 `渠道/模型` 写法：`codex/gpt-5` 指向名为 `codex` 的供应商，而不是 `codex` 渠道下的所有供应商。需要在多个供应商之间均衡时请使用模型路由。同时修复了供应商名与其他渠道同名时，`/openai/v1` 这类供应商入口返回 `no_usable_target` 的问题。

#### 新增

- Vertex 支持按供应商和凭据覆盖区域。
- Devin 支持实时模型发现和签名推理回放。
- 凭据展示访问令牌与刷新令牌的到期时间。
- 支持 Gemini 续写字段和 Gemini 4 Argon 思考控制。
- 文档发布 `llms.txt`、`llms-full.txt` 和 `llms-small.txt`。

#### 修复

- Responses 流式转换随事件输出，不再等待响应结束。
- CLI 发布构建包含 PostgreSQL 和 MySQL 驱动。
- Claude Code 直连 OAuth 身份与 CLI 2.1.299 保持一致。
- Codex 请求不再携带不支持的推理内容。
- 汇总并规范化 Vertex 发布方模型目录。
- 保留上游模型标识，不再隐式添加别名。
- 保留供应商模型名中的斜杠。
- Console 按渠道限制可用的凭据类型。
- 已保存的模型价格显示保持一致。

#### 调整

- Docker Hub 镜像改为 `gproxy2/gproxy`；文档列出 Docker Hub、GitHub、GitLab 和 CNB 镜像仓库。
- 容器镜像改用 Docker Hub 基础镜像，并使用 UPX 压缩二进制。
- 刷新 Rust、Console 和文档依赖。
- Android 版本代码更新为 4001007。
