## v2.1.2

> Fixes garbled `�` replacement characters that could appear in streamed responses when a multi-byte character was split across network chunks.

### English

#### Fixed

- **Streamed multi-byte characters.** SSE decoding previously converted each network chunk to text independently, so a CJK character or emoji cut at a chunk boundary was rendered as `�` replacement characters. Decoders now hold back an incomplete trailing UTF-8 sequence until the next chunk completes it, affecting cross-protocol streaming conversion, response rules, and the claudeweb, geminicli, antigravity, and chatgpt channels. Only genuinely invalid bytes are still replaced.

### 简体中文

#### 修复

- **流式多字节字符。** SSE 解码此前对每个网络分块独立转换文本,当中文字符或 Emoji 恰好被分块边界切断时会显示为 `�` 替换字符。现在解码器会将末尾不完整的 UTF-8 序列暂存,等待下一个分块拼接完成,覆盖跨协议流式转换、响应规则,以及 claudeweb、geminicli、antigravity 和 chatgpt Channel;只有真正非法的字节才会被替换。
