## v4.1.9

> More accurate cache accounting, expanded OpenAI compatibility, Volcengine channels, and Russian localization.
>
> 改进缓存计账与 OpenAI 兼容性，新增火山引擎渠道及俄语本地化。

### English

#### Added

- Add Volcengine Agent and Coding Plan channels.
- Add OpenAI Live and voice APIs, including realtime client-secret support.
- Add Russian localization for the application and documentation.
- Unify offline v2-to-v4 migration through SQLite, including a PostgreSQL export bridge.
- Add sliding tabs for personal and administrator navigation in the Console.

#### Fixed

- Meter cache writes by token count and lifetime, preserve cache retention across markers and protocol conversion, and keep cache reads as a single token count.
- Align OpenAI and Codex request and response types with upstream references, including cache controls, nullable usage, MCP errors and optional function-tool strictness.
- Preserve upstream errors across HTTP, WebSocket and streaming paths.
- Estimate output tokens from generated content when upstream usage is unavailable.
- Display Claude Code cloud-session credits with their expiration.
- Open documentation in the selected Console language and explain URL encoding for proxy credentials.
- Complete API reference translations required by the documentation build.

#### Changed

- Retire the Guardian API and migrate its stored operation references.
- Refresh Rust, Console and documentation dependencies.
- Update Android version code to 4001009.

### 简体中文

#### 新增

- 新增火山引擎 Agent 和 Coding Plan 渠道。
- 新增 OpenAI Live 和语音 API，包括实时会话客户端密钥支持。
- 应用和文档新增俄语本地化。
- 统一通过 SQLite 完成 v2 到 v4 的离线迁移，并提供 PostgreSQL 导出桥接。
- Console 使用滑动标签切换个人与管理员导航。

#### 修复

- 缓存写入按 token 数量和有效期计账，在缓存标记和协议转换中保留缓存有效期；缓存读取仍使用单一 token 计数。
- 根据上游参考文档对齐 OpenAI 和 Codex 请求与响应类型，包括缓存控制、可空用量、MCP 错误及函数工具可省略的 strict 字段。
- 在 HTTP、WebSocket 和流式路径中保留上游错误。
- 上游未返回用量时，根据生成内容估算输出 token。
- 展示 Claude Code 云会话额度及其到期时间。
- Console 按所选语言打开文档，并补充代理凭证 URL 编码说明。
- 补齐文档构建所需的 API 参考翻译。

#### 调整

- 移除 Guardian API，并迁移已存储的相关操作引用。
- 刷新 Rust、Console 和文档依赖。
- Android 版本代码更新为 4001009。
