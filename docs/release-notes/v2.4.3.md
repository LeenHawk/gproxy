## v2.4.3

> Corrects quota-window compatibility and restores the full CI test suite after the v2.4.2 usage-history release.

### English

#### Fixed

- **Stable quota-window compatibility.** Claude Code weekly model and surface windows now keep their stable history keys while displaying their human-readable labels in the Console. Gemini quota buckets likewise retain their resource-qualified keys and expose the model as a display label.
- **Usage snapshot consistency.** Grok Build billing periods without an explicit percentage now report zero percent used, preserving the known quota window and its billing metadata.
- **CI expectations.** Backend tests now reflect the stable quota-window identifiers introduced with credential quota history.

### 简体中文

#### 修复

- **稳定的额度窗口兼容性。** Claude Code 的每周模型与产品面窗口继续使用稳定的历史记录键，同时在 Console 中显示易读标签。Gemini 额度桶也会保留包含资源维度的键，并以模型名作为显示标签。
- **用量快照一致性。** Grok Build 账期缺少明确百分比时，现在会报告已使用 0%，从而保留已知额度窗口及其账期元数据。
- **CI 预期。** 后端测试现已与凭证额度历史引入的稳定额度窗口标识保持一致。
