## v4.1.8

> Claude Code usage-limit modes, new upstream channels, clearer streaming errors, and more reliable request history.
>
> 新增 Claude Code 额度续用模式和上游渠道，改进流式错误处理与请求历史。

### English

#### Added

- Add opt-in Claude Code lower-priority waiting and extended usage grace. Both switches default to off; explicit client `slow` and `extended` headers are supported. Capacity retries remain on the same credential and respect cancellation and host deadlines.
- Add Command Code and Trae China/international channels, and international service selection for WorkBuddy.
- Support channels implemented in external crates for native and Edge hosts, with a working plugin example and integration guide.
- Support batch identity administration and OAuth-client retirement, including reuse of retired OAuth IDs.
- Add localized API references and bilingual tutorials for routing, access control, clients and logs.

#### Fixed

- Align the Claude Code channel with CLI 2.1.302, including User-Agent and billing identity.
- Accept object-form surface quota entries and revalidate only the selected Claude Code reset program, so an unrelated eligibility query cannot block redemption.
- Preserve request-scoped usage-mode permissions through SDK preselection, credential selection and session affinity without clearing quota records or bypassing local budgets and cooldowns.
- Forward upstream streaming errors, terminate Gemini conversion on error frames, and close downstream responses correctly.
- Reconstruct HTTP bodies from capture events and reclaim orphaned capture data while keeping usage accounting separate from request-history retention.
- Keep dialog actions reachable with long text, scope model choices to the selected provider, and batch Console imports and bindings.
- Include upstream 404 responses in credential failure cooldowns.
- Ignore unknown Responses events and handle Codex response metadata events.
- Remove Antigravity's hard-coded Claude output-token ceiling.

#### Changed

- Refresh Rust, Console and documentation dependencies.
- Harden release packaging against stale desktop bundles, Alpine/RISC-V toolchain mismatches, Termux OpenSSL archive conflicts and transient download failures.
- Update Android version code to 4001008.

### 简体中文

#### 新增

- Claude Code 支持按配置启用低优先级等待和额度宽限，两个开关默认关闭，同时支持客户端明确携带的 `slow`、`extended` 请求头。容量不足时在同一凭证上等待重试，并遵守取消信号和主机截止时间。
- 新增 Command Code、Trae 国内版和国际版渠道，WorkBuddy 支持选择国际服务。
- 原生和 Edge 主机支持在外部 crate 中实现渠道，并提供可运行的插件示例与接入指南。
- 支持批量身份管理和 OAuth 客户端退役，可复用已退役的 OAuth ID。
- 新增本地化 API 参考，以及路由、访问控制、客户端和日志的双语教程。

#### 修复

- Claude Code 渠道与 CLI 2.1.302 对齐，包括 User-Agent 和计费身份。
- 支持对象格式的使用场景额度条目；Claude Code 重置时只复核所选方案，避免无关资格查询失败阻断兑换。
- 请求级额度续用许可贯穿 SDK 预筛选、凭证选择和会话绑定，不删除额度记录，也不绕过本地预算与冷却限制。
- 转发上游流式错误，Gemini 转换遇到错误帧时及时终止，并正确关闭下游响应。
- 从捕获事件重建 HTTP 消息体，回收孤立捕获数据，并将用量计账与请求历史保留策略分离。
- 长文本弹窗中的操作按钮保持可达，模型选项限定到所选供应商，Console 导入和绑定改为批量写入。
- 上游 404 响应纳入凭证失败冷却。
- 忽略未知 Responses 事件，并处理 Codex 响应元数据事件。
- 移除 Antigravity 对 Claude 输出 token 数的硬编码上限。

#### 调整

- 刷新 Rust、Console 和文档依赖。
- 改进发布打包，处理旧桌面包残留、Alpine/RISC-V 工具链不匹配、Termux OpenSSL 静态库冲突和临时下载失败。
- Android 版本代码更新为 4001008。
