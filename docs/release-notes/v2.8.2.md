## v2.8.2

> Normalizes Gemini model ids in model-list conversions.

### English

#### Fixed

- **Gemini model-id normalization.** Model-list conversions from Gemini now strip the `models/` resource-name prefix (matching upstream-catalogue ingestion), so canonical ids are directly usable in generation paths; conversions toward the Gemini wire emit proper `models/{id}` resource names.

### 简体中文

#### 修复

- **Gemini 模型 id 归一化。** 来自 Gemini 的模型列表转换现在会剥去 `models/` 资源名前缀(与上游目录摄取规则一致),canonical id 可直接用于生成路径;面向 Gemini wire 的转换则输出规范的 `models/{id}` 资源名。
