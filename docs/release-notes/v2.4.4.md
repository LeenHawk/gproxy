## v2.4.4

> Fixes model-scoped rule matching and refreshes credential usage views with clearer charts, quota meters, and reliable dialog sizing.

### English

#### Fixed

- **Model-scoped rules.** Model filter patterns are now editable in the Console without the suggestion popover taking over the input, and request/response rules correctly match both the inbound model and any routed alternate model across buffered and streaming paths.
- **Credential usage dialog sizing.** Usage charts can no longer expand the dialog grid while being measured, preventing statistic tiles and quota rows from being clipped.

#### Changed

- **Clearer credential usage views.** Credential summaries, comparisons, and quota-cycle history now use stable categorical colors, labeled legends, compact status badges, and severity-colored quota meters. Light and dark themes both provide distinct chart palettes, while redundant daily figures have been removed.

### 简体中文

#### 修复

- **模型范围规则。** Console 中的模型过滤表达式现在可正常编辑，候选弹窗不会再抢占输入；请求与响应规则也会在缓冲及流式路径中同时匹配入站模型和路由后的备用模型。
- **凭证用量弹窗尺寸。** 图表测量期间不再撑大弹窗网格，统计卡片与额度行不会被裁切。

#### 变更

- **更清晰的凭证用量视图。** 凭证概览、对比和额度周期历史现采用稳定的分类配色、带标签的图例、紧凑状态徽标和按严重程度着色的额度进度条；浅色与深色主题均具备清晰可区分的图表色板，并移除了重复的每日数字展示。
