## v4.1.4

### English

- Fix x86_64 Android packages, which crashed at startup in v4.1.3: the UPX loader stopped when Android denied access to `/proc/self/auxv` instead of using its 4 KiB page-size fallback. ARM64 packages are unchanged.
- Build the F-Droid APK with the same per-ABI steps as the release workflow, so F-Droid's rebuild can reproduce the universal reference APK.
- Update Android version code to 4001004.

### 简体中文

- 修复 v4.1.3 中 x86_64 Android 包启动即崩溃的问题：Android 拒绝读取 `/proc/self/auxv` 时，UPX 加载器直接中止，没有使用 4 KiB 页大小的回退逻辑。ARM64 包不受影响。
- F-Droid APK 改用与发布工作流相同的分架构构建步骤，使 F-Droid 重新构建能复现通用参考 APK。
- Android 版本代码更新为 4001004。
