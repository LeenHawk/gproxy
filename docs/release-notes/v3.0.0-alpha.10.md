## v3.0.0-alpha.10

> Restore a direct switch between request usage and quota history.

### English

#### Fixed

- Replace the stacked usage-and-quota page with a segmented switch between Usage records and Quota records, with Usage records selected by default.
- Keep date, provider, and credential filters shared while showing request-specific filters only for Usage records.

#### Changed

- Fetch usage rows, summaries, users, and keys only in the Usage records view; fetch quota history only while the Quota records view is active.

### 简体中文

#### 修复

- 用“用量列表／配额列表”分段滑块替代上下堆叠的用量与配额页面，并默认显示用量列表。
- 日期、供应商和凭证筛选由两个视图共享；用户、API 密钥、模型和请求等筛选只在用量列表显示。

#### 变更

- 仅在用量列表视图请求逐次用量、汇总、用户和密钥数据；仅在配额列表视图激活时请求配额历史。
