## v2.1.4

> Updates Claude protocol support through the July 24, 2026 platform release, including Claude Opus 5, default and ordered refusal fallback routing, current tools, and corrected cross-protocol effort handling.

### English

#### Added

- **Claude Opus 5 protocol support.** Claude Opus 5 and Sonnet 5 are recognized model IDs, the full effort ladder reaches `max`, and current refusal categories, model fallback capabilities, beta headers, and Opus 5 pricing are included.
- **Configurable Fable fallback routing.** Claude API-like channels can use Anthropic's category-aware `"default"` fallback or an ordered chain of one to three models. OpenRouter receives an equivalent explicit model chain, and existing Fable-to-Opus settings are migrated to the new configuration field.
- **Current Claude tool schemas.** Mid-conversation tool additions and removals, `web_search_20260318`, `web_fetch_20260318`, and `response_inclusion` are represented in the native protocol.

#### Fixed

- **Cross-protocol reasoning effort.** Claude `output_config.effort` now maps to OpenAI reasoning effort and Gemini thinking level instead of OpenAI verbosity, preserving `xhigh` and `max` where the destination supports them.
- **Provider fallback availability.** Azure and Amazon Bedrock no longer advertise or inject Anthropic server-side fallback, which those platforms do not support.

### 简体中文

#### 新增

- **Claude Opus 5 协议支持。** 新增 Claude Opus 5 与 Sonnet 5 模型 ID，完整 effort 档位可达 `max`，并同步当前拒绝类别、模型回退能力、Beta Header 与 Opus 5 价格。
- **可配置 Fable 回退路由。** Claude API 类渠道可使用 Anthropic 按拒绝类别维护的 `"default"` 回退，或按顺序配置一至三个模型；OpenRouter 会收到等价的显式模型链，已有 Fable 到 Opus 设置会迁移到新字段。
- **最新 Claude 工具 Schema。** 原生协议现已表示会话中途工具增删、`web_search_20260318`、`web_fetch_20260318` 与 `response_inclusion`。

#### 修复

- **跨协议推理强度。** Claude `output_config.effort` 现在映射到 OpenAI Reasoning Effort 与 Gemini Thinking Level，而不再误映射为 OpenAI Verbosity；目标协议支持时会保留 `xhigh` 与 `max`。
- **Provider 回退可用性。** Azure 与 Amazon Bedrock 不再声明或注入其平台不支持的 Anthropic 服务端回退。
