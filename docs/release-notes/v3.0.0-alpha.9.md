## v3.0.0-alpha.9

> Structured model capabilities for OpenAI, Claude, Gemini, and Codex, plus a clearer self-update flow.

### English

#### Added

- Store model descriptions, instructions, modalities, supported parameters, reasoning levels, service tiers, tools, truncation policy, and capability flags as typed fields and normalized records instead of an opaque metadata blob.
- Merge OpenRouter coverage and pricing with Codex model metadata in the embedded catalog; live provider values remain authoritative and operator overrides are preserved.
- Project the shared metadata into OpenAI extensions, native Claude capabilities, native Gemini model fields, and Codex model records with reasoning presets, service tiers, and non-empty instructions.
- Add an advanced provider-model editor with explicit unknown and known-empty states for repeatable capabilities.

#### Fixed

- Preserve Codex reasoning-level metadata through model discovery instead of reducing it to a boolean.
- Native self-update installations now restart automatically by default and show release notes in a dialog before applying an update.

#### Changed

- The embedded catalog now contains 585 models, including 11 Codex model records and default pricing for 509 models.
- Upgrading from alpha.8 applies model-metadata schema version 3 automatically. Back up the database before upgrading; an alpha.8 binary cannot open a database after this migration.

### 简体中文

#### 新增

- 使用明确字段和规范化子表保存模型说明、指令、模态、支持参数、推理档位、服务档位、工具、截断策略及能力标志，不使用不透明的 metadata blob。
- 内嵌目录合并 OpenRouter 的模型覆盖和价格与 Codex 模型元数据；实时上游值优先，同时保留操作员覆盖。
- 将同一份元数据投影为 OpenAI 扩展、Claude 原生 capabilities、Gemini 原生模型字段，以及包含推理预设、服务档位和非空指令的 Codex 模型记录。
- 供应商模型编辑器新增高级元数据区域，可明确区分重复能力的“未知”和“已知为空”。

#### 修复

- 模型发现不再把 Codex 推理档位压缩成单个布尔值，完整保留档位与说明。
- 原生安装的自更新默认自动重启，并在应用更新前通过弹窗展示发布说明。

#### 变更

- 内嵌目录现包含 585 个模型，其中有 11 个 Codex 模型记录，509 个模型带默认价格。
- 从 alpha.8 升级会自动应用模型元数据 schema version 3。升级前请备份数据库；迁移后 alpha.8 二进制无法再打开该数据库。
