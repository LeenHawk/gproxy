## v2.6.3

> Narrows Cline model discovery to models that are free or included with Cline Pass.

### English

#### Fixed

- **Cline model eligibility.** The `/recommended-models` response now contributes only its `free` and `clinePass` groups to GPROXY's model list. General `recommended` entries are excluded so clients see models that can be used without separate BYOK billing or that are covered by Cline Pass.

### 简体中文

#### 修复

- **Cline 模型可用范围。** GPROXY 现在只从 `/recommended-models` 响应中合并 `free` 与 `clinePass` 分组，并排除普通 `recommended` 项，让客户端只看到免费模型或 Cline Pass 已覆盖的模型。
