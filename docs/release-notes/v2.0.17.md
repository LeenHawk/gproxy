## v2.0.17

> Adds native installers and background startup controls, ships RISC-V GNU and musl releases and Docker images, supports Claude partner models on Vertex AI, and restores protocol-aware prompt caching across Claude, OpenAI, and Gemini conversions.

### English

#### Added

- **Native installers and background startup.** Releases now include Windows MSI, macOS DMG, Linux DEB, and Android APK packages alongside portable ZIP archives. Desktop installations can register per-user background startup, with a Console setting to enable or disable it without persisting passwords, keys, DSNs, or authenticated proxy URLs.
- **RISC-V GNU and musl distributions.** Linux RISC-V 64 now ships as GNU and static musl ZIP/DEB artifacts. Both variants also join the GHCR multi-architecture manifests, so the default and `-musl` images cover amd64, arm64, and riscv64.
- **Native Claude models on Vertex AI.** Vertex channels can route Claude partner models through the native Anthropic `rawPredict` and `streamRawPredict` endpoints, including token counting and streaming behavior.
- **Protocol-aware prompt caching.** Claude cache controls and OpenAI explicit breakpoints now survive Chat Completions and Responses conversions. OpenAI `explicit` mode keeps the final four Claude-compatible breakpoints, `implicit` mode preserves its automatic cache policy, and Claude/Gemini to OpenAI conversions produce stable `prompt_cache_key` values for reusable conversation prefixes.
- **Download center.** The documentation now provides categorized direct downloads for installers, portable binaries, Docker images, and edge bundles in English and Chinese, with download-first guidance for non-developers.

#### Fixed

- **Provider model catalogue refresh.** Scoped model listing now refreshes provider catalogues through the normal execution and failover path, persists newly discovered models, and applies route permissions consistently to aggregate and provider-specific results.
- **Android package compatibility.** The APK launcher templates no longer depend on Java lambdas or generated `R` resources, avoiding build failures in the minimal release toolchain.
- **Windows MSI structure.** Installer files are split into valid WiX components so native Windows packages build and install reliably.
- **Cache breakpoint hygiene.** String content is normalized into text blocks when required, unsupported cache targets are skipped or moved to a valid preceding block, and cache-write usage is retained through conversion and billing.

#### Changed

- **Cache breakpoint naming and migration.** The rewrite-rule target is now named `message`, with an automatic persistence migration from the previous value and clearer Console labels.
- **Installation guidance.** The docs and READMEs now direct regular users to prebuilt downloads and GitHub Releases instead of source builds, document RISC-V and musl images, and add Star History and GitHub Sponsors links.

### 简体中文

#### 新增

- **原生安装包与后台启动。** Release 现在除便携 ZIP 外，还会发布 Windows MSI、macOS DMG、Linux DEB 和 Android APK。桌面安装版可以注册用户级后台启动，并可在 Console 中开关；注册过程不会持久化密码、密钥、DSN 或带认证信息的代理 URL。
- **RISC-V GNU 与 musl 发行版。** Linux RISC-V 64 现在同时提供 GNU 和静态 musl 的 ZIP/DEB 产物。两种版本也已加入 GHCR 多架构 manifest，默认镜像和 `-musl` 镜像均覆盖 amd64、arm64 与 riscv64。
- **Vertex AI 原生 Claude 模型。** Vertex 渠道现在可以通过 Anthropic 原生 `rawPredict` 与 `streamRawPredict` 端点路由 Claude partner models，并支持 token counting 与流式响应。
- **协议感知提示缓存。** Claude cache control 与 OpenAI 显式断点现在可以在 Chat Completions 和 Responses 转换中保留。OpenAI `explicit` 模式转 Claude 时保留最后四个兼容断点，`implicit` 模式保留自动缓存策略；Claude/Gemini 转 OpenAI 时还会为可复用对话前缀生成稳定的 `prompt_cache_key`。
- **下载中心。** 中英文文档新增分类下载页，集中提供安装包、便携二进制、Docker 镜像与 Edge Bundle 的直链，并明确建议非开发者优先下载预构建版本。

#### 修复

- **Provider 模型目录刷新。** Scoped 模型列表现在通过正常执行与 failover 路径刷新 Provider catalogue，持久化新发现的模型，并对聚合与 Provider 专属结果统一应用 route permission。
- **Android 打包兼容性。** APK launcher template 不再依赖 Java lambda 或生成的 `R` resource，避免最小 release toolchain 下的构建失败。
- **Windows MSI 结构。** Installer 文件已拆分为合法的 WiX component，使 Windows 原生安装包能够稳定构建和安装。
- **缓存断点清理。** 必要时会把字符串 content 规范化为 text block；不支持断点的 block 会被跳过或把断点移动到前一个合法 block；cache-write usage 也会在转换与计费链路中保留。

#### 调整

- **缓存断点命名与迁移。** Rewrite rule target 现统一命名为 `message`，持久化数据会从旧值自动迁移，Console label 也更清晰。
- **安装指引。** 文档与 README 现在引导普通用户优先使用预构建下载和 GitHub Releases，不再默认推荐源码构建；同时补充 RISC-V、musl 镜像、Star History 与 GitHub Sponsors 链接。
