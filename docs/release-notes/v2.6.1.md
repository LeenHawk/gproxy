## v2.6.1

> Limits Cline model discovery to its curated recommendation feed so model sync no longer exposes the full upstream BYOK catalogue.

### English

#### Fixed

- **Cline model availability.** Model discovery now reads `/api/v1/ai/cline/recommended-models` and merges the `recommended`, `free`, and `clinePass` groups in their upstream order. Duplicate IDs are removed and each row retains its name, description, tags, and Cline group, preventing the broader 409-model upstream catalogue from being presented as account-ready models.

### 简体中文

#### 修复

- **Cline 模型可用性。** 模型发现改用 `/api/v1/ai/cline/recommended-models`，并按上游顺序合并 `recommended`、`free` 与 `clinePass` 分组。重复模型 ID 会被移除，每项仍保留名称、描述、标签和 Cline 分组，避免再把包含 409 个模型的上游全量目录当作账号可用模型展示。
