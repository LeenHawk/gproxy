## v2.8.1

> Routes native Imagen image generation: OpenAI create-image converts to the Imagen `:predict` endpoint for `imagen-*` models.

### English

#### Added

- **Native Imagen route.** Imagen `:predict` wire models (instances, parameters, output options, predictions), Gemini endpoint synthesis for `CreateImage` targeting `imagen-*` models, and a same-operation transform pair between OpenAI image generation and Imagen predict (size to aspect ratio, sample count, output MIME/compression; predictions map back to inline `b64_json` data). `gemini-*-image` models keep the existing generate-content route.

### 简体中文

#### 新增

- **Imagen 原生路由。** 新增 Imagen `:predict` wire 模型（instances、parameters、输出选项、predictions）、面向 `imagen-*` 模型的 `CreateImage` Gemini 端点合成，以及 OpenAI 生图与 Imagen predict 之间的同操作转换对（尺寸→宽高比、张数、输出 MIME/压缩；predictions 映射回内联 `b64_json`）。`gemini-*-image` 系模型继续走既有的 generate-content 路由。
