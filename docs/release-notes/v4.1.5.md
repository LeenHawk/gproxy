## v4.1.5

### English

- Rebuild vendored OpenSSL in every release build instead of reusing it from the build cache. Cached builds embedded an earlier commit's build date, so F-Droid's clean rebuild could not reproduce the reference APK.
- Publish the headless Android CLI as a Termux package, `gproxy-headless-android-<arch>.deb`. It provides the same `gproxy` command and replaces the full `gproxy` package.
- Compress Windows ARM64 executables with LZMA, as on x64.
- Update the Claude Code (2.1.296) and Codex (0.162.1) client versions.
- Remove Deno deployment support; Cloudflare remains the edge platform.
- Align the Android build's JVM targets with Java 21.
- Update Android version code to 4001005.

### 简体中文

- 每次发布构建都重新编译内置的 OpenSSL，不再复用构建缓存。缓存里的 OpenSSL 带着更早提交的编译时间，导致 F-Droid 从零构建时无法复现参考 APK。
- 无前端 Android CLI 增加 Termux 安装包 `gproxy-headless-android-<arch>.deb`，提供同一个 `gproxy` 命令，安装时会替换完整版 `gproxy` 包。
- Windows ARM64 可执行文件改用 LZMA 压缩，与 x64 一致。
- 更新 Claude Code（2.1.296）和 Codex（0.162.1）客户端版本。
- 移除 Deno 部署支持，边缘部署继续使用 Cloudflare。
- Android 构建的 JVM 目标版本统一为 Java 21。
- Android 版本代码更新为 4001005。
