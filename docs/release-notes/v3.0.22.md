## v3.0.22

> Keep Codex priority requests and upstream routing hints in sync.
> 修复 Codex priority 请求与上游路由提示不同步的问题。

### English

#### Fixed

- Rebuild the Codex `x-codex-routing-hint` header from the final upstream model and service tier after model variants and request rewrites, for both HTTP and Responses WebSocket requests.
- Normalize Codex `service_tier: fast` to `priority`, matching the Codex CLI wire format.
- Prevent duplicate WebSocket fields from overwriting normalized request fields, including model and service tier, while preserving extension fields. Usage records continue to report the actual tier returned by the upstream.

### 简体中文

#### 修复

- 在模型变体和请求改写完成后，按最终上游模型及服务档位重新生成 Codex `x-codex-routing-hint` 请求头，覆盖 HTTP 和 Responses WebSocket 请求。
- 将 Codex `service_tier: fast` 规范为 `priority`，与 Codex CLI 实际发送格式一致。
- 修复 WebSocket 重复字段覆盖已规范化请求字段（包括模型和服务档位）的问题，并保留扩展字段。用量记录仍以上游返回的实际档位为准。
