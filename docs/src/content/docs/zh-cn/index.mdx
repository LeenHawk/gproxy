## 它是怎么建的

<CardGrid>
	<Card title="一张 router，三个宿主" icon="random">
		Workers 宿主挂载的是原生二进制服务的同一个 axum router。它新增的路由就是
		边缘提供的路由，没有第二张表会漂走。
	</Card>
	<Card title="每一层都在收窄" icon="approve-check">
		认证产出一个调用方，准入产出一个 Provider 集合和一个凭证集合，引擎拿到的
		恰好就是这些。下层绝不重新打开上层收窄过的东西。
	</Card>
	<Card title="没有中间格式" icon="setting">
		转换是两种线格式之间的直接映射。上游规范的变化速度快过任何中枢格式能跟上
		的速度，而转换保真度正是这个产品本身。
	</Card>
	<Card title="没有东西绕过漏斗" icon="warning">
		每一条到达上游的路径都经同一个出口定价、扣减与观测。绕过它的路径就是未计量
		流量，所以那样的路径不存在。
	</Card>
</CardGrid>
