本页从 Rust 协议类型、管理 DTO 和宿主路由声明生成，请求与响应分别使用各自的 Serde 规则。展开端点可查看参数、载荷、状态码以及引用的[数据结构](/zh-cn/reference/api-schemas/)。

共用的转发路径根据请求头选择协议，`stream: true` 切换为流式操作。SSE 结构描述解码后的单个事件，WebSocket 结构描述升级连接后的消息；二进制和 multipart 载荷保留各自的内容类型。

转发路径也可使用 provider 或命名空间前缀。Codex 专用路径要求指定 Codex provider 名称。挂载、鉴权及管理权限范围见[路由与端点](/zh-cn/reference/routing-table/)。
