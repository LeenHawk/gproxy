## Docker 镜像

默认镜像使用 GNU libc，`-musl` tag 使用静态 musl 版本。两套镜像都发布
`linux/amd64`、`linux/arm64` 和 `linux/riscv64`。

<CardGrid>
  <LinkCard title="GNU 多架构镜像" description="ghcr.io/leenhawk/gproxy:latest" href="https://github.com/LeenHawk/gproxy/pkgs/container/gproxy" />
  <LinkCard title="musl 多架构镜像" description="ghcr.io/leenhawk/gproxy:latest-musl" href="https://github.com/LeenHawk/gproxy/pkgs/container/gproxy" />
</CardGrid>

```bash
docker pull ghcr.io/leenhawk/gproxy:latest
# 静态 musl 版本：
docker pull ghcr.io/leenhawk/gproxy:latest-musl
```

持久化存储和运行参数见 [Docker 部署](/zh-cn/deployment/docker/)。
