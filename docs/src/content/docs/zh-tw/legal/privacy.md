生效日期：2026 年 10 月 9 日
釋出者：Leen Hawk

GPROXY 是執行在你的裝置上的開源 AI API 閘道器。釋出者不提供 AI 帳號、模型訂閱或託管閘道器帳號。本說明適用於 GPROXY 應用，不代替你自行接入的第三方服務的隱私政策。

應用處理的資訊
配置和使用閘道器時，應用會處理供應商帳號及 API 憑據、閘道器使用者及訪問金鑰、請求和回應，以及用量、額度、錯誤、耗時等執行記錄。請求可能包含你或接入閘道器的用戶端提供的個人資訊、提示詞、圖片、音訊、檔案等內容。請勿提交你無權提供的資訊。

儲存和保留時間
配置、憑據和記錄儲存在你選擇的資料庫及儲存位置。請求內容的記錄範圍和保留時間取決於日誌及保留設定。使用你配置的遠端資料庫或儲存服務時，資料不只儲存在本機。應用會顯示憑據加密是否可用，請勿假定所有已儲存憑據均已加密。請妥善保護裝置、資料庫、備份和金鑰。

網路傳輸及第三方
應用會將請求及必要憑據傳送到你配置的供應商和服務地址；如果你選擇境外服務，資訊也會相應傳送至境外。供應商登入、模型列表、額度查詢、模型資源下載及遠端資料庫連線也會訪問對應服務。這些服務有獨立的條款、保留規則和隱私政策，請在瞭解並同意其處理方式後配置使用。

介面字型隨應用內建，無需從外部服務下載。字型不可用時，介面使用系統字型。商店安裝版本由相應商店提供應用更新，並適用該商店的政策。GPROXY 不會自動向釋出者傳送閘道器資料，包括分析或支援用途。

權限用途
網路權限用於閘道器及你配置的網路服務。Android 通知和前臺服務權限用於顯示由你啟動或由你允許開機自啟的閘道器的執行狀態，並提供停止入口。在 Android 上，可選的啟動和電池設定用於離開應用後繼續執行，可以在應用或系統設定中調整。HarmonyOS 背景執行能力取決於裝置和實際授予的權限。商店版本不申請安裝下載 APK 的權限。

你的選擇和刪除方式
你可以選擇供應商、服務地址、儲存、用戶端、日誌及保留設定。監聽地址預設僅限本機；向網路開放監聽會改變其他人訪問實例的範圍。本機上的其他應用也能連線本地監聽地址，但模型 API 請求仍需閘道器訪問金鑰，請妥善保管金鑰。可以透過管理介面刪除支援刪除的帳號、憑據和記錄。刪除全部實例資料前請停止閘道器。清除 Android 應用儲存或解除安裝會移除應用私有本地資料；匯出檔案、備份、遠端資料庫及供應商持有的資料需另行刪除。HarmonyOS 應用資料可以透過系統應用和儲存設定刪除；另行儲存的備份也需單獨刪除。刪除本地資料不會刪除供應商的副本。你可以隨時停止使用、刪除應用資料並解除安裝。
