CLI / 容器的控制台位於 `/console`，同一個應用包含個人頁面和管理頁面。使用部署時配置的帳號登入；
控制台透過 `/portal/api/login` 登入，使用 HttpOnly 會話 Cookie。

個人費用預算只在概覽中隨用量一起展示，沒有單獨的個人配額頁。預算由管理員在對應使用者、
API Key、組織或團隊上設定，個人概覽只讀。

## 首次啟動

Application 全新實例先顯示三步設定精靈，完成後進入應用內控制台。CLI / 容器在首次啟動時建立管理員，透過瀏覽器 `/console/` 登入，不顯示應用內精靈。詳細步驟見[安裝](/zh-tw/getting-started/installation/)。

## 管理範圍

控制台結合 `/portal/api/context` 的個人功能和 `/admin/api/context` 返回的管理能力。
實例管理員管理閘道器配置。組織和團隊管理員透過同一個供應商入口管理範圍內的憑證；組織和團隊頁只展示有權訪問的物件及費用預算，不開放身份增刪改或供應商配置。

管理多個組織或團隊時，在帳戶選單中選擇範圍。管理請求透過 `x-gproxy-admin-scope`
攜帶後端返回的範圍標識。切換範圍會關閉編輯和登入視窗，並更換對應的查詢快取；正在提交的寫入
需要完成後才能切換。個人頁面不依賴管理範圍。

## 配置入口

| 控制台路徑 | 功能 |
| --- | --- |
| `/console/providers` | 供應商配置、憑證、模型、協議轉換、重寫規則繫結及端點覆蓋 |
| `/console/model-routes` | 以用戶端模型名命名的跨供應商路由、成員、權重及回退層級 |
| `/console/rule-sets` | 重寫規則、排序和整組儲存 |
| `/console/transfer` | 配置匯入匯出 |
| `/console/clients` | 可複用連線配置 |
| `/console/settings` | 實例與日誌設定 |
| `/console/tokenizer` | 詞表下載及模型詞表繫結 |
| `/console/update` | 當前宿主支援的更新操作 |

供應商的“路由規則”標籤管理操作與協議轉換；“模型路由”負責選擇上游供應商，兩者分別配置。

配置表格支援選擇當前頁記錄並批次刪除；有啟用開關的記錄還支援批次啟停。修改篩選、翻頁或切換
管理範圍會清空選擇。每次批次寫入使用現有配置 API 的事務。

## 憑證與上游登入

在供應商的憑證標籤內管理憑證，新增憑證和登入流程自動繫結該供應商。
歸屬只能選擇當前管理範圍允許的物件。租戶目錄只展示供應商名稱和支援的操作，不開放閘道器配置。

編輯憑證開啟同一個面板，包含“基本設定”“本地限額”“上游額度”三個標籤。憑證行也可直接
開啟上游額度、測試或刪除憑證。金鑰檢視與重新整理位於基本設定的金鑰欄位下，狀態修改與健康重置位於
狀態區域。測試使用緊湊彈窗，自動讀取可用模型，分別展示結果、耗時和回覆。上游額度以金額、
次數和重置時間展示；生成測試會真實請求上游。

“登入新增憑證”根據渠道支援情況顯示：

- 瀏覽器授權：開始後開啟授權連結，再貼上包含 `code` 和 `state` 的完整回撥 URL。
  註冊的本機回撥頁面可能無法開啟，仍可複製位址列中的回撥地址。控制台不會啟動本機回撥監聽服務。
- 裝置碼：開啟驗證連結，輸入頁面顯示的驗證碼。控制台按後端返回的間隔輪詢；成功、拒絕、過期或
  關閉視窗後停止輪詢。
- Cookie 交換：提交已有的瀏覽器會話 Cookie，由渠道換取憑證。

登入會話繫結發起使用者、管理範圍和憑證歸屬。完成後只返回憑證 ID，不返回金鑰。關閉未完成流程會
停止介面操作，後端快取會話自然過期；重新整理頁面不會恢復登入精靈。

上游登入介面均為 `/admin/api/credential-login` 下的 POST：`/authcode/start`、
`/authcode/complete`、`/device/start`、`/device/poll`、`/cookie/exchange`，沿用憑證管理的範圍檢查。
按憑證發現和測試模型分別使用 `/admin/api/credentials/{id}/models/discover` 和 `/models/test`。

## 配額與價格

管理員在“我的帳戶 → 金鑰”和“訪問控制 → 使用者金鑰”中新建金鑰時，可直接在名稱下方
開啟費用預算，填寫金額和週期。金鑰與初始預算在同一事務中儲存，預算校驗失敗不會建立金鑰。
已有金鑰的編輯面板包含“基本設定”和“費用預算”兩個標籤。普通使用者保留原有的金鑰自助操作，
費用預算由管理員設定。

使用者、API Key、組織和團隊上的入口統一稱為“費用預算”，新增和編輯直接在當前面板完成。
費用按 USD 十進位制字串傳輸，供應商/憑證的請求次數限額使用 `count` 單位。

供應商的“設定 → 預設憑證限額”分別作用於**每個憑證**，不是供應商共享總預算。此處只展示
配置，實際用量和重置時間在具體憑證內檢視。啟用的憑證同名規則覆蓋供應商預設規則；“恢復繼承”
會刪除這條憑證單獨設定。停用單獨設定也會重新使用已啟用的供應商預設規則，不表示取消全部限額。

憑證限額卡片同時展示來源、上限、實際用量和下次重置時間。組織/團隊管理員可檢視生效限額，
由實例管理員修改。本地編輯突出金額或次數、週期、適用模型、啟用狀態；自定義時長及固定週期的
起點放在高階選項，儲存時不會再開啟第二層彈窗。

重置供應商預設規則會影響當前繼承它的所有憑證，確認提示會明確說明範圍。繼承卡片沒有單憑證
重置按鈕；憑證單獨規則和呼叫方預算只重置自己的規則。這些操作均不重置上游帳號額度。

價格規則可作用於全部供應商或指定供應商，模型匹配支援 `*` 和 `?`，同一模型可有多條按操作區分的
規則。全域性價格在模型目錄中編輯，供應商價格在供應商的模型標籤中編輯；模型與價格共用現有入口，費率和階梯價格也在同一彈窗管理。

## 匯入匯出

匯入匯出文件包含閘道器配置，不包含身份、用量或請求日誌。匯出預設不包含憑證金鑰，選擇包含時使用
已儲存的密封格式。匯入接受當前 v4 文件格式。

檔案摘要展示版本和記錄數量，不代表後端已經預檢。“合併”更新相同 ID 的記錄，並保留未提及的記錄；
“替換”還會刪除檔案中未包含的配置記錄，僅限可匯出的配置類別。

從使用不同主金鑰的實例匯入加密憑證時，填寫源主金鑰以重新加密；不填寫時，加密憑證要求目標使用
相同金鑰。提交結束後介面清除源主金鑰。

匯入使用事務，提交後宿主過載執行態設定。請檢視返回的警告和跳過數量：過載失敗表示配置已經匯入、
執行態過載出現問題，不表示資料庫寫入已經回滾。

## 字型

控制台內建 Noto Sans、Noto Sans SC/TC 和 Noto Sans Mono 及其授權說明。CLI 和 Application 從本地載入字型，無需外部下載。Edge 將同一套字型作為同源靜態資源部署。Headless 套件不包含控制台及其字型。

## 構建控制台

執行 `pnpm --dir console lint`、`pnpm --dir console test` 和 `pnpm --dir console build`。
構建會進行型別檢查、Vite 打包，並將資源複製到控制台嵌入目錄。隨後構建的原生程式可在 `/console`
提供該資源；Edge 部署把同一份資源作為閘道器前的靜態資源部署。
