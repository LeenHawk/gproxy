## Common tasks

<CardGrid>
  <Card title="Manage accounts" icon="setting">
    Manage API keys, OAuth, and Cookie credentials in one console, with health and upstream allowance information.
  </Card>
  <Card title="Route models" icon="random">
    Give clients a stable model name, distribute requests by weight, and configure fallback providers.
  </Card>
  <Card title="Connect protocols" icon="puzzle">
    Use OpenAI, Claude, and Gemini API formats with streaming. Available operations depend on the channel and upstream.
  </Card>
  <Card title="Track usage and costs" icon="document">
    Set user and key permissions and budgets, then inspect requests and billing details.
  </Card>
</CardGrid>
