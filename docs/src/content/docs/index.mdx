## How It Is Built

<CardGrid>
	<Card title="One router, three hosts" icon="random">
		The Workers host mounts the same axum router the native binary serves.
		A route it grows is a route the edge serves, with no second table to drift.
	</Card>
	<Card title="Each layer narrows" icon="approve-check">
		Authentication produces a caller, admission produces a provider set and a
		credential set, and the engine is handed exactly those. Nothing below
		re-opens what was narrowed above.
	</Card>
	<Card title="No intermediate format" icon="setting">
		Conversion is direct between two wire formats. Upstream specifications
		change faster than any pivot format can track, and conversion fidelity is
		the product.
	</Card>
	<Card title="Nothing skips the funnel" icon="warning">
		Every path that reaches an upstream is priced, charged and observed through
		the same exit. A path around it would be unmetered traffic, so there is
		not one.
	</Card>
</CardGrid>

:::note[v4 is built from source]
There is no release pipeline yet — no installers, no published container image
and no signed artifacts. See [Installation](/getting-started/installation/).
:::
