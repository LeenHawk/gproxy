Эта ссылка создается на основе `AppConfig` и его вложенных типов Rust с `schemars`. Имена полей следуют за Serde; значения по умолчанию взяты из настроек по умолчанию Rust. Форма является общей для собственных и пограничных хостов. См. [Конфигурация](/ru/reference/configuration/) для флагов CLI, переменных среды и приоритета.

Проверка схемы охватывает сериализованную структуру. Проверки во время выполнения, например, декодируется ли мастер-ключ в 32 байта или была ли скомпилирована серверная часть, по-прежнему применяются.
