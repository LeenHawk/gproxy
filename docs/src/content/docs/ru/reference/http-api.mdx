Этот справочник генерируется на основе типов протокола Rust, DTO управления и объявлений маршрутов хоста. Схемы запросов и ответов используют соответствующие контракты Serde. Разверните операцию, чтобы увидеть ее параметры, полезные данные, коды состояния и ссылку на [структуры данных](/ru/reference/api-schemas/).

Общие пути пересылки выбирают протокол из заголовков запросов. `stream: true` выбирает операцию потоковой передачи. Схемы SSE описывают каждое событие декодированных данных; Схемы WebSocket описывают сообщения после обновления. Двоичные и составные полезные данные сохраняют свои собственные типы контента.

Пути пересылки также могут использовать префикс провайдера или пространства имен. Для путей, специфичных для Codex, требуется имя провайдера Codex. См. [Маршрутизация и конечные точки](/ru/reference/routing-table/) для выбора монтирования, аутентификации и административной области.
