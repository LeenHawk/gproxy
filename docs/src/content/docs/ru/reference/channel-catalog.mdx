Этот каталог создается путем вызова `descriptor()` каждого скомпилированного канала и объявлений маршрута обслуживания. Он включает в себя все каналы из группы функций `channels` SDK. Развернутый двоичный файл может включать меньший набор.

Возможности описывают реализованные дополнительные интерфейсы, а не доступ к реальной учётной записи или матрицу поддерживаемых операций протокола. Заполнители конфигурации являются примерами, а не значениями по умолчанию во время выполнения. Маршруты обслуживания провайдеров требуют монтирования провайдера или пространства имен; доступ также зависит от роли клиента API и представления службы. Перечисленный маршрут может быть ограничен или запрещен, как указано в его классификации. См. [Провайдеры и учётные данные](/ru/guides/providers/) для настройки.
