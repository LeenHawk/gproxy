Эти определения являются общими для [HTTP API ссылка](/ru/reference/http-api/) и загружаемого документа OpenAPI. Определения `Input_` описывают принятые запросы; Определения `Output_` описывают сериализованные ответы. Ссылки сохраняют рекурсивные типы, варианты, обязательные поля и значения, допускающие значение NULL.

Разверните определение, чтобы прочитать его полную схему. Имена полей протокола, значения перечислений и идентификаторы типов остаются неизменными на разных языках.
