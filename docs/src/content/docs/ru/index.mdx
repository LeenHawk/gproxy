## Общие задачи

<CardGrid>
  <Card title="Управление аккаунтами" icon="setting">
    Управляйте ключами API, учётными данными OAuth и Cookie в одной консоли, используя информацию о работоспособности и разрешениях провайдера.
  </Card>
  <Card title="Маршрутизация моделей" icon="random">
    Дайте клиентам стабильное имя модели, распределите запросы по весу и настройте резервных провайдеров.
  </Card>
  <Card title="Протоколы подключения" icon="puzzle">
    Используйте форматы OpenAI, Claude и Gemini API для потоковой передачи. Доступные операции зависят от канала и провайдера.
  </Card>
  <Card title="Отслеживайте использование и затраты" icon="document">
    Установите разрешения и бюджеты для пользователей и ключей, а затем проверьте запросы и детали расчёта стоимости.
  </Card>
</CardGrid>
