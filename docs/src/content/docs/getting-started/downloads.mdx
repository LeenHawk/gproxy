### Android

APK installations can update from Console. GPROXY verifies the signed APK and
then opens Android's system installer for user approval. Portable Android ZIP
installations update `gproxy.bin` together with their C++ runtime.

## Docker images

The default image uses GNU libc. The `-musl` tag uses the static musl build.
Both image families publish `linux/amd64`, `linux/arm64`, and `linux/riscv64`.

<CardGrid>
  <LinkCard title="GNU multi-architecture image" description="ghcr.io/leenhawk/gproxy:latest" href="https://github.com/LeenHawk/gproxy/pkgs/container/gproxy" />
  <LinkCard title="musl multi-architecture image" description="ghcr.io/leenhawk/gproxy:latest-musl" href="https://github.com/LeenHawk/gproxy/pkgs/container/gproxy" />
</CardGrid>

```bash
docker pull ghcr.io/leenhawk/gproxy:latest
# Static musl alternative:
docker pull ghcr.io/leenhawk/gproxy:latest-musl
```

See [Docker deployment](/deployment/docker/) for persistent storage and runtime
configuration.
