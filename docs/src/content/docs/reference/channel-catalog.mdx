This catalogue is generated by calling each compiled channel's `descriptor()`
and service-route declarations. It includes every channel in the SDK's `channels`
feature group. A deployed binary may enable a smaller set.

Capabilities describe implemented optional interfaces, not live account access
or a matrix of supported protocol operations. Configuration placeholders are
examples, not runtime defaults. Vendor service routes require a provider or
namespace mount; access also depends on caller role and service view. A listed
route may be restricted or refused, as indicated by its classification.
See [Providers & Credentials](/guides/providers/) for setup.
