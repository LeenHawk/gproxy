and the downloadable OpenAPI document. `Input_` definitions describe accepted
requests; `Output_` definitions describe serialized responses. References preserve
recursive types, variants, required fields and nullable values.

Expand a definition to read its complete schema. Protocol field names, enum
values and type identifiers remain unchanged across languages.
