## v4.2.3

> Fixed Claude Code quota resets and updated the Antigravity channel for CLI 1.5.4.
>
> 修复 Claude Code 额度重置，并将 Antigravity 渠道更新到 CLI 1.5.4。

### English

#### Fixed

- Claude Code quota reset options now carry their title, description and affected windows from the channel, so the console shows the 5-hour, weekly, full and Fable resets as the upstream describes them, including the once-a-week 5-hour reset.
- A Fable reset closes only the Fable window and returns this week's Fable usage to the weekly allowance; the total weekly cycle and its recorded cost are kept. A Fable reset with no Fable usage this week reports that there is nothing to give back.
- A reset that only refreshes usage, such as a refund, no longer closes every quota cycle.
- Antigravity labels the `gemini-4-carbon` models with their hub `model_enum` values.
- Antigravity follows CLI 1.5.4 and hub 2.30.0: the hub user agent is updated, and the `antigravity` TLS preset offers `h2, http/1.1` and sends Go's HTTP/2 settings, connection window and pseudo-header order.

#### Changed

- The daily synchronization of the signed MSIX package to the Microsoft Store is restored.
- Rewrote the introduction and feature sections of the README.
- Refreshed Console, Rust, Cloudflare deployment and CI action dependencies, including wreq-util 0.2.1.

### 简体中文

#### 修复

- Claude Code 额度重置选项改由渠道提供标题、说明和影响的额度窗口，控制台按上游的说法显示 5 小时、每周、完整和 Fable 重置，包括每周一次的 5 小时重置。
- Fable 重置只关闭 Fable 窗口，并把本周 Fable 用量退回每周额度；每周总额度周期及已记录的费用保持不变。本周没有 Fable 用量时，会提示没有可退回的用量。
- 只刷新用量的重置（例如退款）不再关闭所有额度周期。
- Antigravity 为 `gemini-4-carbon` 模型补充 hub 的 `model_enum` 标签。
- Antigravity 跟进 CLI 1.5.4 和 hub 2.30.0：更新 hub 的 user agent；`antigravity` TLS 预设改为提供 `h2, http/1.1`，并发送 Go 的 HTTP/2 设置、连接窗口和伪头部顺序。

#### 变更

- 恢复每日向 Microsoft Store 同步已签名 MSIX 包。
- 重写 README 的介绍和功能部分。
- 刷新控制台、Rust、Cloudflare 部署及 CI action 依赖，包含 wreq-util 0.2.1。
