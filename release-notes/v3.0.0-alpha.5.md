## v3.0.0-alpha.5

> Correct subscription quota cycles and expose individual settled usage records.

### English

#### Fixed

- Detect quota resets from decreasing usage or changed upstream intervals; attribute usage by upstream send time and reconcile late settlement without double counting.
- Limit quota controls and probes to supported subscription credentials, including credential-mode differences within a channel.
- Send stable OpenCode session headers for every inference format.

#### Changed

- Refresh active subscription credentials every ten minutes with deduplication and failure backoff.
- Show local cycle tokens, settled USD, and sample-based capacity estimates in credential details.
- Display per-request usage with server-side pagination, full-filter totals, and details independent of request-log retention.

#### Breaking Alpha Schema Change

- This release changes usage and credential-quota tables without an in-place migration for earlier alpha databases. Back up and rebuild the affected statistics tables before starting this version on an existing alpha installation. Preserve credentials, configuration, identities, and billing/admission state.
- New usage must carry the actual upstream send time; old-alpha timestamp fallback and legacy cycle-state reconstruction are removed. The separate v2 historical-usage importer is retained.

### 简体中文

#### 修复

- 已用额度倒降或上游区间变化均可识别新轮次；按上游发送时间归属用量，迟到结算可补账且不重复计数。
- 仅支持订阅额度的凭证展示额度控件并执行探测，同一渠道内区分凭证模式。
- 所有推理格式统一携带稳定的 OpenCode 会话头。

#### 变更

- 活跃订阅凭证按十分钟刷新，合并重复探测并在失败后退避。
- 凭证详情展示本周期本地 Token、已结算 USD 和基于增量样本的额度估算。
- 用量页改为逐次记录，支持服务端分页、全筛选范围汇总和独立于请求日志的详情。

#### Alpha 数据结构不兼容变更

- 用量和凭证额度相关表采用新结构，不提供旧 alpha 数据库原地迁移。已有 alpha 实例必须先备份并重建相关统计表，再启动新版；凭证、配置、身份和计费准入状态应保留。
- 新用量必须包含实际上游发送时间，不再回退旧 alpha 时间或补全旧周期状态；独立的 v2 历史用量导入仍保留。
