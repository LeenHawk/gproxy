## v4.2.4

> Use Gemini through an AI Studio Playground session, track credential quotas across providers, and choose how users and API keys share rate limits.
>
> 支持通过 AI Studio Playground 网页会话调用 Gemini，可在控制台集中查看各供应商的凭证额度，并按用户或 API 密钥分别计算限流用量。

### English

#### Added

- The `playground` channel supports Gemini generation, streaming, function calls, model discovery and local token counting. Import a Cookie-Editor export with HttpOnly cookies and configure your own WAA signer via `proof_server_url`. GPROXY saves cookies reissued by Google and rotates the session cookies while the credential is in use.
- The Cloudflare channel supports embeddings, reranking and model discovery. It can look up the account ID when a token lists a single account. Quota tracking covers the 10,000 free daily Workers AI neurons for `@cf/` models and tracks AI Gateway credits separately for third-party models.
- The Console's credential usage page shows active quota windows across providers. Filter by provider or open a credential to check its latest upstream usage.
- Instance administrators can apply permission and rate-limit rules to everyone, a user, an API key, or a specific user and key together. A rate limit can use one shared counter (the default for existing rules) or count separately per user or key.
- Administrators can upload a custom Console ZIP under Settings → General. Open `/console/?console=builtin` to recover the built-in interface if the upload fails to load.
- Body rewrite rules support RFC 6902 JSON Patch. Select the whole body as the target and use JSON Pointer paths in the patch operations.
- `gproxy-client-sdk` adds conversation compaction through `Client::compact` and portable settings for reasoning display and answer verbosity. Optional features provide local token estimates and image normalization, including EXIF orientation correction, resizing and thumbnail generation.

#### Fixed

- The client SDK now recognizes GIF output from OpenAI image generation.
- A rejected provider key during model discovery no longer signs the operator out of the Console. The admin and portal APIs return HTTP 502 with the upstream error details. Claude and Gemini requests that carry both a dedicated API-key header and `Authorization` now use the dedicated key.
- Codex compatibility follows CLI 0.169.1, including updated image and model catalog formats. Request conversion handles the reasoning and tool requirements of GPT-6.2 Astra and Sol. The channel supplies retry guidance for server overload and transient HTTP 429 errors. Responses image inputs default to `auto` when detail is omitted.
- Claude Code follows client 2.1.326 and queries quota reset offers independently, so an eligibility check that hits a rate limit no longer hides other available resets.
- Antigravity follows IDE 2.7.0 and CLI 1.5.10 (hub 2.32.2), uses HTTP/1.1 by default and recognizes Gemini Hydrogen model labels. The bundled model catalog and prices have also been refreshed.
- The Console lists rules that apply to everyone, makes the channel selector searchable and keeps the save button visible in inline editors.

#### Packaging

- The WinGet workflow submits updates after the Microsoft Store signs the MSIX packages and updates an existing package pull request when one is open. Release builds use UPX 5.3.1 on targets that enable compression.

### 简体中文

#### 新增

- 新增 `playground` 渠道，支持 Gemini 生成、流式响应、函数调用、模型发现和本地 token 计数。使用时需导入 Cookie-Editor 导出的完整 Cookie（含 HttpOnly），并通过 `proof_server_url` 配置自建 WAA 签名服务。凭证使用期间，GPROXY 会保存 Google 重新签发的 Cookie，并定期轮换会话 Cookie。
- Cloudflare 渠道支持向量嵌入、重排序和模型发现。令牌只关联一个可见账户时，可自动获取账户 ID。`@cf/` 模型按 Workers AI 每日 10,000 个免费神经元统计额度，第三方模型单独跟踪 AI Gateway 余额。
- 控制台新增凭证用量页，可集中查看各供应商凭证当前的额度窗口，按供应商筛选，或打开单个凭证查询上游最新用量。
- 实例管理员可将权限或限流规则应用于所有人、指定用户、指定 API 密钥，或指定用户与密钥的组合。限流可共用一个计数器，也可按用户或密钥分别计数。已有规则默认继续共用计数器。
- 管理员可在「设置 → 常规」上传自定义控制台 ZIP 包。如果自定义页面无法加载，可打开 `/console/?console=builtin` 进入内置控制台。
- 正文重写规则支持 RFC 6902 JSON Patch。选择整个正文为目标后，即可在补丁操作中用 JSON Pointer 路径指定要修改的位置。
- `gproxy-client-sdk` 新增 `Client::compact` 会话压缩方法，以及跨协议的推理展示和回答详略设置。可选功能支持本地 token 估算和图像规范化，包括按 EXIF 校正方向、缩放和生成缩略图。

#### 修复

- 客户端 SDK 现可识别 OpenAI 图像生成返回的 GIF。
- 查询模型时，即使上游拒绝供应商密钥，操作员也能继续使用控制台。管理和门户 API 会返回 HTTP 502 并附上上游错误详情。Claude 和 Gemini 请求同时携带专用密钥头和 `Authorization` 时，优先使用专用密钥。
- Codex 渠道跟进 CLI 0.169.1，更新图像和模型目录格式。请求转换遵循 GPT-6.2 Astra 和 Sol 对推理与工具调用的要求。上游过载或临时返回 HTTP 429 时，渠道会向 CLI 提供重试提示。Responses 图像输入省略精细度时默认使用 `auto`。
- Claude Code 渠道跟进客户端 2.1.326，独立查询各项额度重置选项。其中一项资格查询触发限流时，其余可用选项仍会显示。
- Antigravity 渠道跟进 IDE 2.7.0 和 CLI 1.5.10（hub 2.32.2），默认使用 HTTP/1.1，并能识别 Gemini Hydrogen 模型标签。同步更新了内置模型目录和价格。
- 控制台可查看和编辑适用于所有用户的规则，渠道选择器支持搜索，行内编辑时保存按钮保持可见。

#### 打包

- WinGet 工作流在 Microsoft Store 完成 MSIX 签名后提交更新。如果对应软件包已有待合并的 PR，会直接更新该 PR。启用压缩的发布目标使用 UPX 5.3.1。
