## v4.2.0

> Realtime sessions and the Gemini Interactions API, per-credential quota caps, a typed client SDK, and fixes across protocol conversion, channels and packaging.
>
> 新增实时会话与 Gemini Interactions API、单凭据额度上限和类型化客户端 SDK，并修复协议转换、各渠道与打包中的大量问题。

### English

#### Added

- Gemini Interactions API, with protocol conversion to and from the other dialects.
- Realtime sessions resolve their model in the gateway like other operations: OpenAI Realtime from the handshake `?model=`, Gemini Live from the first `setup` frame, through admission and alias/route mapping. The AI Studio channel serves Gemini Live.
- Per-credential quota cap (`cap_percent`, 1–100, editable in the Console): a reported window or budget spent to the cap counts as exhausted until it resets. New sessions and round-robin picks lean towards credentials with more headroom.
- Per-provider request timeout and stream idle timeout, edited in the provider form; left empty, each inherits the global setting.
- Credential affinity now lasts as long as the prompt cache stays warm (5 minutes, an hour for Codex or after a one-hour cache write) instead of a flat 24 hours, and is dropped when a reply barely used the cache.
- Upstream rejections are classified from the response body: rate limits, exhausted quota, missing credit (402 now fails over), unserved models and request faults. A credential that refused is skipped for the rest of that request.
- Usage records keep the model the upstream response names next to the routed model; the Console marks them when they differ.
- A Claude client on a Responses upstream (such as Claude Code on Codex) sees the reasoning as thinking, and the reasoning is replayed across tool-loop steps.
- Claude Code channel: present as the Claude Agent SDK (`client_identity`), with the billing block aligned to the CLI.
- Copilot CLI channel: models that only answer `/responses` are sent there, chosen per model from the catalogue.
- `gproxy completions <shell>` and `gproxy man`; a branded `--help`, and `--version` names the full commit, target, profile and features.
- Announcements are read from the release host the instance updates from, falling back to the other hosts.
- The Console's optional font pack is downloaded from public npm CDNs, each file checked against its SHA-256 name. Tables offer 100 rows per page and remember the page size.
- `gproxy-client`: a typed client SDK for the OpenAI, Claude and Gemini dialects, covering generation, embeddings, images, speech, transcription, realtime sessions, model listing and asset delivery (inline or through S3).
- GPROXY Headless has its own Microsoft Store product (`9ND7FQQMV566`), submitted with each stable release alongside Desktop and CLI. A Scoop bucket installs CLI, Headless and Desktop: `scoop bucket add gproxy https://github.com/LeenHawk/scoop-bucket`.

#### Changed

- The default request body limit is 128 MiB (was 50 MiB). Existing instances keep their stored value. Channels no longer impose their own smaller body limits; the host's request and response limits are the only size settings.
- Gemini Live is served only at its official path; the `/ws/v1beta/BidiGenerateContent` alias is removed.
- A Scoop install keeps its data in `%LOCALAPPDATA%\GPROXY`, like MSIX and WinGet installs.
- Every release binary is packed with gproxy's UPX fork; RISC-V binaries use the AUIPC filter again and are about 11% smaller.
- The documentation site moved to Mintlify.

#### Fixed

- Protocol conversion: tool results are paired with their calls; Chat continuation fragments with empty tool IDs are accepted; a Responses assistant turn becomes one Chat message; root unions in tool schemas are folded for Claude; Responses `reasoning.summary` maps to Claude thinking display; adaptive thinking is sent to adaptive Claude models with clamped budgets and stays visible when a budget is converted; Claude cache TTLs keep Anthropic's required order; an OpenAI `prompt_cache_key` maps to Claude automatic caching; unspecified function-tool `strict` is omitted in Chat conversion; null `context_management` and `document_title` are accepted from Claude; unsigned Gemini 3 function calls are marked to skip validation; over-long prompt refusals carry across Claude and OpenAI shapes.
- Streams: an error event is sent when conversion fails mid-stream, and streams no longer fail when the upstream changes the model name.
- Channels follow their current clients: Codex CLI 0.167.0 (keeping `prompt_cache_options.ttl`), Claude Code 2.1.318 and Agent SDK 0.3.318 (accepting `chan_` billing project IDs and sending the `tool-provenance-2026-10-26` beta), and the Antigravity CLI 1.5.2 with hub 2.29.0.
- Antigravity: Claude tool schema arrays get an `items` schema, disabled catalogue models are hidden, Claude Code's billing line is dropped from the system instruction, and project discovery and OAuth token handling are updated.
- Codex: input items that cannot resolve without storage are dropped; device and account metadata are bound to the selected credential.
- Claude Code: main-loop betas are sent for clients without their own.
- Command Code: required CLI workspace context is provided; reported cache and reasoning usage is preserved.
- Multipart requests: the model selector is read before routing and the upstream model is bound in the form.
- `claude-opus-5-5` is priced at Opus 5.5 rates.
- Gemini model catalogues always include `baseModelId`; model discovery follows `nextPageToken`.
- Packaged executables on x86_64, RISC-V and PowerPC64 Linux could fail at startup depending on where their code ended, and the RISC-V packer filter could corrupt data; both are fixed in the UPX fork (upx/upx#18968, #18970).
- Console: picker data sources keep separate page sizes; the rules and routing provider tabs have icons.
- The Console's `minimatch` is overridden to 11.0.4 (GHSA-g3hv-75wg-m249).

### 简体中文

#### 新增

- 支持 Gemini Interactions API，并可与其他协议互相转换。
- 实时会话与其他操作一样在网关中解析模型：OpenAI Realtime 取握手的 `?model=`，Gemini Live 取首个 `setup` 帧，并经过准入与别名/路由映射。AI Studio 渠道提供 Gemini Live。
- 单凭据额度上限（`cap_percent`，1–100，可在控制台编辑）：上报的窗口或预算用到上限即视为耗尽，直到重置。新会话和轮询选择会偏向剩余额度更多的凭据。
- 可为单个供应商设置请求超时和流空闲超时，在供应商表单中编辑；留空则各自继承全局设置。
- 凭据亲和的有效期改为跟随提示缓存的保温时间（5 分钟；Codex 或写入一小时缓存后为一小时），不再固定 24 小时；回复几乎未使用缓存时解除亲和。
- 按响应体对上游拒绝进行分类：限流、额度耗尽、余额不足（402 现在会故障转移）、模型不可用和请求错误。拒绝过的凭据在本次请求余下的尝试中跳过。
- 用量记录在路由模型之外，额外保存上游响应中声明的模型；两者不同时控制台会标出。
- Claude 客户端使用 Responses 上游（如 Claude Code 接 Codex）时，推理内容以 thinking 呈现，并在工具循环各步之间回放。
- Claude Code 渠道：可伪装为 Claude Agent SDK（`client_identity`），计费块与 CLI 保持一致。
- Copilot CLI 渠道：只支持 `/responses` 的模型改走该接口，按模型目录逐个选择。
- 新增 `gproxy completions <shell>` 与 `gproxy man`；`--help` 带品牌标识，`--version` 显示完整提交、目标、构建配置和特性。
- 公告改为从实例所用的发布主机读取，失败时依次尝试其他主机。
- 控制台的可选字体包改为从公共 npm CDN 下载，每个文件都按 SHA-256 文件名校验。表格提供每页 100 行，并记住分页大小。
- `gproxy-client`：面向 OpenAI、Claude、Gemini 协议的类型化客户端 SDK，涵盖生成、embeddings、图像、语音、转写、实时会话、模型列表和资源投递（内联或经 S3）。
- GPROXY Headless 拥有独立的 Microsoft Store 产品（`9ND7FQQMV566`），每个正式版与 Desktop、CLI 一同提交。新增 Scoop bucket，可安装 CLI、Headless 和 Desktop：`scoop bucket add gproxy https://github.com/LeenHawk/scoop-bucket`。

#### 变更

- 默认请求体上限改为 128 MiB（原为 50 MiB），已有实例保留已保存的值。各渠道不再自行设定更小的体积限制，主机的请求与响应上限是唯一的大小设置。
- Gemini Live 只在官方路径提供，移除 `/ws/v1beta/BidiGenerateContent` 别名。
- 通过 Scoop 安装时数据保存在 `%LOCALAPPDATA%\GPROXY`，与 MSIX、WinGet 安装一致。
- 所有发布二进制改用 gproxy 维护的 UPX 分支压缩；RISC-V 二进制重新启用 AUIPC 过滤，体积减小约 11%。
- 文档站迁移到 Mintlify。

#### 修复

- 协议转换：工具结果与对应调用正确配对；接受 Chat 续传片段中的空工具 ID；Responses 的助手轮次合并为一条 Chat 消息；发送给 Claude 的工具 schema 折叠根级 union；Responses 的 `reasoning.summary` 映射为 Claude thinking 显示；向自适应 Claude 模型发送 adaptive thinking 并限制预算，预算转换后 thinking 仍可见；Claude 缓存 TTL 保持 Anthropic 要求的顺序；OpenAI `prompt_cache_key` 映射为 Claude 自动缓存；Chat 转换中省略未指定的函数工具 `strict`；接受 Claude 返回的 null `context_management` 和 `document_title`；未签名的 Gemini 3 函数调用标记为跳过校验；超长提示的拒绝在 Claude 与 OpenAI 形态间正确转换。
- 流式：流中途转换失败时发送错误事件；上游更换模型名不再导致流失败。
- 各渠道对齐当前客户端版本：Codex CLI 0.167.0（保留 `prompt_cache_options.ttl`），Claude Code 2.1.318 与 Agent SDK 0.3.318（接受 `chan_` 计费项目 ID，并发送 `tool-provenance-2026-10-26` beta），Antigravity CLI 1.5.2 与 hub 2.29.0。
- Antigravity：Claude 工具 schema 中的数组补充 `items`；隐藏目录中标为禁用的模型；从系统指令中去掉 Claude Code 的计费行；更新项目发现与 OAuth 令牌处理。
- Codex：丢弃无存储时无法解析的输入项；设备与账户元数据绑定到所选凭据。
- Claude Code：为未自带 beta 的客户端发送主循环 beta。
- Command Code：提供 CLI 所需的工作区上下文；保留上报的缓存与推理用量。
- Multipart 请求：在路由前读取模型选择，并在表单中绑定上游模型。
- `claude-opus-5-5` 按 Opus 5.5 价格计费。
- Gemini 模型目录始终包含 `baseModelId`；模型发现会跟随 `nextPageToken`。
- 压缩后的 x86_64、RISC-V、PowerPC64 Linux 程序可能因代码段结尾位置而启动失败，RISC-V 压缩过滤还可能损坏数据；均已在 UPX 分支中修复（upx/upx#18968、#18970）。
- 控制台：选择器的各数据源分别记住分页大小；规则与路由的供应商标签页补上图标。
- 控制台的 `minimatch` 覆盖为 11.0.4（GHSA-g3hv-75wg-m249）。
