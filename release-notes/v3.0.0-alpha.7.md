## v3.0.0-alpha.7

> Reset-aware subscription quotas and per-request usage, including disabled and orphaned credential compatibility.

### English

#### Fixed

- Quota capability inspection no longer uses data-plane availability checks. Disabled credentials remain visible without becoming usable upstream.
- Historical credential records whose provider is gone report no quota capability instead of breaking the whole credential list. The records are preserved.
- Detect new quota rounds from decreasing usage or changed intervals; attribute requests by upstream send time and reconcile late settlement without double counting.
- Send stable OpenCode session headers across inference formats.

#### Changed

- Probe active subscription credentials every ten minutes with deduplication and failure backoff; ordinary API credentials have no quota controls.
- Keep cycle Token/USD usage and sample-based estimates in expanded credential details, without a quota-summary table column.
- Show individual usage records with server-side pagination, full-filter totals, and details independent of retained request logs.

#### Breaking Alpha Schema Change

- Before deploying on an earlier alpha database, back up and rebuild the usage and credential-quota statistics tables. This release does not perform an in-place migration of those old statistics. Preserve credentials, configuration, identities, and billing/admission state.
- New usage requires actual upstream send time. Old-alpha time fallback and cycle reconstruction are removed; the separate v2 historical-usage importer remains.
- Use alpha.7 rather than alpha.5 for this schema. The alpha.6 workflow was cancelled before publication to include the orphaned-credential case.

### 简体中文

#### 修复

- 额度能力查询与数据面可用性检查分离，禁用凭证仍可查看，但不能用于上游请求。
- 上游已删除的孤立凭证显示为无额度能力，不再阻断整个凭证列表，也不删除原记录。
- 已用额度倒降或区间变化触发新轮次；按上游发送时间归属请求，支持迟到补账和去重。
- 各推理格式统一携带稳定的 OpenCode 会话头。

#### 变更

- 活跃订阅凭证按十分钟探测，带去重和失败退避；普通 API 凭证不展示额度控件。
- 本周期 Token、USD 和增量样本估算保留在凭证展开详情，不再显示额度摘要列。
- 用量页展示逐次记录、服务端分页及全筛选范围汇总，详情不依赖请求日志保留。

#### Alpha 数据结构不兼容变更

- 旧 alpha 上线前必须先备份并重建用量和凭证额度统计表，不提供这些旧统计的原地迁移；凭证、配置、身份和计费准入状态应保留。
- 新用量必须包含实际上游发送时间，不再回退旧 alpha 时间或重建旧周期状态；独立的 v2 历史用量导入仍保留。
- 新统计结构请使用 alpha.7，不要部署 alpha.5；alpha.6 为合入孤立凭证处理，已在发布前取消。
