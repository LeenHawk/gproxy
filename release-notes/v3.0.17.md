## v3.0.17

> Restore release identity and update signature verification for cross-built binaries.
> 修复交叉编译产物的发布身份和更新签名校验。

### English

#### Fixed

- Pass the update signing public key, build version, release channel, build hash, and installation kind into cross build containers. Linux musl and RISC-V GNU release binaries now embed the correct release identity and update verification key (#254).
- The fix also applies to musl container images built from these binaries. Users of affected v3.0.16 standalone packages must manually download and replace the binary once, because their existing binary cannot verify update manifests.

### 简体中文

#### 修复

- 向 cross 构建容器透传更新签名公钥、构建版本、发布通道、构建哈希和安装类型，修复 Linux musl 与 RISC-V GNU 发布产物缺失发布身份及更新验证公钥的问题（#254）。
- 使用这些二进制的 musl 容器镜像同步修复。受影响的 v3.0.16 独立安装包无法验证更新清单，需要手动下载并替换一次二进制。
