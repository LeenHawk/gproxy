## v3.0.19

> Fix mobile model variant editing and Cline OAuth credential rotation.
> 修复手机端模型变体编辑超宽和 Cline OAuth 刷新覆盖 API Key 的问题。

### English

#### Fixed

- Keep model variant cards, long preset selections, suggested names, and request-field previews within the editor on narrow screens. Long previews wrap and dropdowns stay within the viewport.
- Preserve manually configured Cline API keys during OAuth refresh. New OAuth logins store access tokens separately instead of copying them into `api_key`.
- Recognize legacy login tokens stored in `api_key` and use the `workos:` authorization format for plan usage queries. Refresh removes legacy token copies while retaining real API keys (#255).

#### Upgrade notes

- API keys already overwritten by older versions cannot be recovered automatically. Re-enter the original key if API-key authentication is required; existing OAuth credentials use the corrected login-token path.

### 简体中文

#### 修复

- 修复窄屏下模型变体卡片、较长的预设选项、建议名称和请求字段预览撑宽编辑器的问题；长预览自动换行，下拉菜单限制在视口内。
- Cline OAuth 刷新时保留手动配置的 API Key；新的 OAuth 登录单独保存访问令牌，不再复制到 `api_key`。
- 兼容旧版本写入 `api_key` 的登录令牌，套餐用量查询使用正确的 `workos:` 认证格式；刷新时清理旧令牌副本，同时保留真实 API Key（#255）。

#### 升级说明

- 旧版本已覆盖的原始 API Key 无法自动恢复。如需继续使用 API Key 认证，请重新填写原始 Key；已有 OAuth 凭证将使用修正后的登录令牌认证路径。
