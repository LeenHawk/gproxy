## v4.2.1

> An OpenDesign channel, `gproxy-client-sdk` and `gproxy-store` on crates.io, a rewritten manual, and a fix for a mislabelled rule preset.
>
> 新增 OpenDesign 渠道，`gproxy-client-sdk` 和 `gproxy-store` 发布到 crates.io，文档全面重写，并修正一个名称错误的规则预设。

### English

#### Added

- `opendesign` channel for the OpenDesign Go / Cloud subscription, with an API key from the account dashboard: Chat Completions, Responses and Claude Messages on `https://amr-link.open-design.ai`, plus the model list. It has no quota query yet.
- `gproxy-client-sdk` and `gproxy-store` are published to crates.io with the other library crates.

#### Changed

- The in-process client backend moved from `gproxy_client_sdk::backend::Embedded` to `gproxy_sdk::ClientBackend`, behind `gproxy-sdk`'s new `client-sdk` feature. The API is unchanged; `gproxy-client-sdk` no longer depends on the engine.
- `gproxy-store` is MIT-licensed, like the other library crates it builds on.
- The documentation is rewritten in all four languages and regrouped into overview, installation and upgrades, tutorial, administration, reference and development. Architecture, embedding, adding a channel and building from source moved under `/development/`; the old addresses redirect.
- Windows release builds are signed in a separate job that waits for SignPath approval.
- Console dependencies: i18next 27 and react-i18next 18.

#### Fixed

- The pi-mono compatibility preset was listed as "the agent-mono" with the id `the agent`. It is `pi` / `pi-mono` again.
- The privacy notice on the documentation site shows its section headings again.

### 简体中文

#### 新增

- 新增 `opendesign` 渠道，用于 OpenDesign Go / Cloud 订阅，使用账户后台签发的 API Key：在 `https://amr-link.open-design.ai` 上提供 Chat Completions、Responses、Claude Messages 和模型列表。暂不支持额度查询。
- `gproxy-client-sdk` 和 `gproxy-store` 与其他库 crate 一起发布到 crates.io。

#### 变更

- 进程内客户端后端从 `gproxy_client_sdk::backend::Embedded` 移到 `gproxy_sdk::ClientBackend`，需要打开 `gproxy-sdk` 新增的 `client-sdk` feature。接口不变；`gproxy-client-sdk` 不再依赖引擎。
- `gproxy-store` 改为 MIT 许可证，与它所依赖的其他库 crate 一致。
- 文档四种语言全部重写，并重新分为概述、安装与升级、入门、管理指南、参考和开发几部分。架构、嵌入、添加渠道和从源码构建移到 `/development/` 下，旧地址会自动跳转。
- Windows 发布包改在单独的任务中签名，该任务等待 SignPath 审批。
- 控制台依赖升级到 i18next 27 和 react-i18next 18。

#### 修复

- pi-mono 兼容预设被显示为“the agent-mono”，id 为 `the agent`，现已恢复为 `pi` / `pi-mono`。
- 文档站的隐私说明重新显示各节标题。
