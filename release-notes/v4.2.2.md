## v4.2.2

> Updated Claude Messages compatibility, Claude Code 2.1.321, and the bundled model catalog.
>
> 更新 Claude Messages 兼容性、Claude Code 2.1.321 渠道及内置模型目录。

### English

#### Added

- Portable generation-request token counting in `gproxy-client-sdk`, with model and token-count operations exposed as IR modules.
- Typed Claude Messages `thread` requests. Native requests retain their thread references; cross-protocol creation converts the full conversation and reports that the target cannot create a Claude thread.

#### Fixed

- Cross-protocol thread continuation now fails explicitly instead of converting only the new turn and losing the server-held history. Replay the full conversation to convert it.
- Fable/Mythos 5.2 conversion respects always-on adaptive thinking and relaxes forced tool choice to `auto`, including OpenRouter model names.
- Claude Code thread continuation no longer receives an injected system prompt. GA fast mode on Opus 5.5 and Fable 5.2 no longer adds a legacy beta header.
- Generated documentation references publish only to the documentation repository's `main` branch.

#### Changed

- SQLite batching uses the SQLx `execute_batch` fork in place of the vendored SQLite driver.
- Refreshed Console and Rust dependencies, including RSA 0.10 with updated Vertex JWT signing.
- Claude Code identity updated to 2.1.321 and Agent SDK identity to 0.3.321. Valid client-supplied background dispatcher attribution is preserved; ordinary CLI requests omit it.
- Refreshed the bundled OpenRouter catalog: 87 additions and 47 removals, for 717 total models after the existing Codex and curated entries are merged. Fable 5.2 base input/output prices are $8/$40 per million tokens.

### 简体中文

#### 新增

- `gproxy-client-sdk` 新增可移植生成请求的 token 计数，并将模型和计数操作组织为 IR 模块。
- 为 Claude Messages 的 `thread` 请求增加类型定义。同协议请求保留线程引用；跨协议创建请求转换完整会话，并提示目标无法创建 Claude 线程。

#### 修复

- 跨协议续接线程时明确报错，避免只转换新一轮消息而丢失服务端历史。需要转换时，请重放完整会话。
- Fable/Mythos 5.2 转换遵循始终启用 adaptive thinking 的规则，并将强制工具选择放宽为 `auto`，包含 OpenRouter 模型名称。
- Claude Code 线程续接不再注入 system 提示；Opus 5.5 和 Fable 5.2 已正式提供的 fast mode 不再自动添加旧 beta 头。
- 自动生成的文档参考仅发布到文档仓库的 `main` 分支。

#### 变更

- SQLite 批量执行改用 SQLx 的 `execute_batch` 分支，替代仓库内置的 SQLite 驱动副本。
- 刷新控制台和 Rust 依赖，包含 RSA 0.10 及对应的 Vertex JWT 签名适配。
- Claude Code 身份更新到 2.1.321，Agent SDK 身份更新到 0.3.321。保留客户端提供的合法后台任务派发来源，普通 CLI 请求省略该字段。
- 刷新内置 OpenRouter 目录：新增 87 项、移除 47 项，合并现有 Codex 和精选条目后共 717 个模型。Fable 5.2 的基础输入/输出价格为每百万 token $8/$40。
