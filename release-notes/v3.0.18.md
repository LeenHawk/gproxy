## v3.0.18

> Align the Claude Code channel with CLI 2.1.280.
> 同步 Claude Code CLI 2.1.280 的渠道身份、OAuth 权限和账单字段。

### English

#### Fixed

- Pin `find-msvc-tools` to 0.1.12 to restore Windows builds with `cc` 1.4.4; 0.1.13 changes the temporary-file flag to an incompatible type.

- Preserve valid optional Claude Code billing fields when rebuilding the system block: workload, subagent flag, previous request ID, prompt ID, and the new turn origin. Invalid values are omitted using the CLI's validation rules.

#### Changed

- Update the Claude Code user agent and version-derived billing suffix to CLI 2.1.280, verified against the official binary and a local request capture.
- Include `user:plugins` in default OAuth login and refresh scopes, including refreshes of older credentials; preserve optional project scopes.
- Include dependency updates for indexmap, crossbeam-utils, crossbeam-queue, compression-codecs, and find-msvc-tools.

### 简体中文

#### 修复

- 将 `find-msvc-tools` 锁定为 0.1.12，修复 0.1.13 临时文件标志类型变化导致 `cc` 1.4.4 无法编译 Windows 产物的问题。

- 重建 Claude Code 系统账单块时，保留合法的工作负载、子代理标记、上一请求 ID、提示 ID 及新增的轮次来源字段；按 CLI 的校验规则丢弃非法值。

#### 变更

- 将 Claude Code User-Agent 和随版本计算的账单后缀更新至 CLI 2.1.280，已通过官方二进制检查和本地请求抓包核对。
- 默认 OAuth 登录及刷新权限增加 `user:plugins`，旧凭据刷新时也会申请；继续保留已有的可选项目权限。
- 包含 indexmap、crossbeam-utils、crossbeam-queue、compression-codecs 和 find-msvc-tools 的依赖更新。
