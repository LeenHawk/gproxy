## v4.1.14

> Fix Antigravity's default backend and GitLab/WinGet release automation.
>
> 修复 Antigravity 默认后端及 GitLab、WinGet 自动发布流程。

### English

#### Fixed

- Use `https://daily-cloudcode-pa.googleapis.com` as Antigravity's default base URL.
- Synchronize the version tag to GitLab before creating its release, so a stalled repository mirror does not prevent publication.
- Decode GitHub CLI responses as UTF-8 in WinGet automation on Windows, avoiding errors when checking existing pull requests containing non-ASCII text.

### 简体中文

#### 修复

- Antigravity 默认地址改为 `https://daily-cloudcode-pa.googleapis.com`。
- 创建 GitLab Release 前先同步版本标签，避免仓库镜像停滞导致发布失败。
- Windows 上的 WinGet 自动发布脚本显式按 UTF-8 解码 GitHub CLI 响应，修复检查含非 ASCII 文本的已有 PR 时发生的编码错误。
