## v3.0.0-alpha.8

> Quota history charts, visible reset credits, and request duration and output speed.

### English

#### Added

- Show remaining upstream quota over time within each round, plus a cross-round range chart with minimum, maximum, and last valid values.
- Filter both charts by provider, credential/quota cycle, and round; switch between remaining percentage, tokens, and USD. Cycle details appear below the charts.
- Persist quota observations with a schema migration and calculate historical samples with settled local usage.
- Display request duration and output tokens per second in usage records.

#### Fixed

- Fetch reset-credit metadata even when recent quota observations are already available. Reset-capable credentials always show the credit row, including zero or an unknown count, above quota details.

#### Changed

- Remove the old aggregate quota estimate block and verbose estimation and refresh notices.
- Upgrading from alpha.7 creates the observation table automatically. Earlier unsaved observations are not reconstructed; earlier-alpha statistics compatibility requirements from alpha.7 still apply.

### 简体中文

#### 新增

- 展示单轮次内剩余上游额度随时间变化的折线图，以及跨轮次最小值、最大值和最后有效值的范围图。
- 两张图支持供应商、凭证／配额周期和具体轮次筛选，可切换剩余比例、令牌及 USD；具体周期明细放在图下方。
- 通过数据库结构升级保存历史额度观测，结合本机已结算用量计算历史样本。
- 用量记录展示请求耗时和输出 TPS。

#### 修复

- 已有近期额度观测时仍读取重置卡信息。支持重置的凭证始终在配额明细上方显示卡数，包括 0 和未取到的状态。

#### 变更

- 删除原来的总额度估算区块，以及冗长的估算和刷新说明。
- 从 alpha.7 升级会自动创建观测表，不补造过去未保存的观测；更早 alpha 的统计结构兼容要求仍按 alpha.7 发布说明执行。
