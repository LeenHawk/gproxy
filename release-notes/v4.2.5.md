## v4.2.5

> A packaging release that corrects the WinGet manifest for GPROXY Desktop.
>
> 本次为打包更新，修正 GPROXY Desktop 的 WinGet 清单。

### English

#### Packaging

- WinGet manifests list only the commands that the MSIX package provides. GPROXY Desktop is started from the Start menu, so its manifest no longer lists the `gproxy-desktop` command, which belonged to the portable ZIP. The CLI and Headless packages keep `gproxy` and `gproxy-headless`.

### 简体中文

#### 打包

- WinGet 清单只列出 MSIX 包实际提供的命令。GPROXY Desktop 从开始菜单启动，清单不再列出便携 ZIP 时期的 `gproxy-desktop` 命令。CLI 和 Headless 仍提供 `gproxy` 和 `gproxy-headless`。
