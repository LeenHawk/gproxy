# GPROXY 4.0.3

> Control thinking-block forwarding across all channels, preserve Claude thinking budgets, and improve application packaging and release isolation.

## English

### Added

- A **Forward thinking blocks** switch in every provider's configuration, enabled by default. Turning it off removes historical thinking/reasoning blocks and signatures from Claude, Responses, Chat and Gemini requests, including Responses WebSocket traffic. Text, tool calls and controls for newly generated thinking remain intact.
- Mobile store build variants, privacy notices and listing materials, plus daily synchronization of Microsoft-signed MSIX packages from the Store.

### Fixed

- Preserve explicit Claude enabled-thinking token budgets during protocol conversion.
- Isolate GitLab release manifests by tag so publishing one update channel does not replace another channel's manifest.
- Upgrade the serverless deployment ZIP library to fix a ZIP64 parsing vulnerability.
- Restore attribution for the bundled DeepSeek tokenizer vocabulary.
- Preserve existing macOS CLI service registrations while aligning the internal service identity.

### Changed

- Unify the application identifier as `com.leenhawk.gproxy.app` and align CLI identity handling. Existing Microsoft Store product identities remain unchanged.
- Update hosted deployment templates to use the prebuilt v4.0.3 packages and advance the mobile store build version to 4000003. Store build preparation does not imply store approval or publication.

## 简体中文

### 新增

- 所有供应商配置新增 **传递思考块** 开关，默认开启。关闭后，移除 Claude、Responses、Chat 和 Gemini 请求历史中的思考块及签名，也覆盖 Responses WebSocket；保留正文、工具调用以及本次生成的思考参数。
- 新增移动端商店构建变体、隐私提示和上架材料，并每日同步 Microsoft Store 返回的微软签名 MSIX 包。

### 修复

- 协议转换时保留 Claude 显式启用思考模式所设置的 Token 预算。
- GitLab 发布清单按版本标签隔离，避免发布一个更新通道时覆盖另一个通道的清单。
- 升级 Serverless 部署所用的 ZIP 库，修复 ZIP64 解析漏洞。
- 恢复内置 DeepSeek 分词器词表的许可署名。
- 对齐 CLI 内部服务标识时保留已有 macOS 服务注册。

### 调整

- 应用标识统一为 `com.leenhawk.gproxy.app`，并对齐 CLI 标识处理；已有 Microsoft Store 产品标识保持不变。
- 托管部署模板更新为使用 v4.0.3 预编译包，移动端商店构建版本号更新为 4000003。构建准备完成不代表已通过商店审核或已上架。
