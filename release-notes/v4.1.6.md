## v4.1.6

> More reliable credential renewal, clearer upstream usage attribution, and simpler CLI installation.
>
> 改进凭据续期、上游用量归属展示和 CLI 安装体验。

### English

#### Added

- Show upstream usage attribution in the Console and support filtering usage records by attribution.
- Add one-line CLI installers for Unix and Windows to the download documentation.

#### Fixed

- Renew credentials before refresh tokens expire and refresh access tokens five minutes before expiry.
- Supply the default redirect URI for Codex browser OAuth when it is omitted.
- Send a per-key workspace for Claude API keys that are not scoped to a workspace.
- Keep download platform cards in independent columns for a more compact layout.

#### Changed

- Consolidate installation instructions into Download & Install.
- Stop publishing musl DEB packages; musl builds use Alpine APK packages instead.
- Refresh Rust, Console, and documentation dependencies.
- Update Android version code to 4001006.

### 简体中文

#### 新增

- Console 展示上游用量归属，并支持按归属筛选用量记录。
- 下载文档新增 Unix 和 Windows CLI 一键安装命令。

#### 修复

- 在刷新令牌到期前续期凭据，并在访问令牌到期前五分钟刷新。
- Codex 浏览器 OAuth 未指定回调地址时，补全默认回调地址。
- 为未绑定 workspace 的 Claude API 密钥发送独立的 workspace。
- 下载页面的平台卡片改为独立列布局，减少空白。

#### 调整

- 将安装说明整合到「下载与安装」页面。
- 停止发布 musl DEB 包；musl 构建改用 Alpine APK 包。
- 刷新 Rust、Console 和文档依赖。
- Android 版本代码更新为 4001006。
