GPROXY privacy information
Effective date: 9 October 2026
Publisher: Leen Hawk

GPROXY is an open-source AI API gateway that runs on your device. The publisher does not provide an AI account, model subscription, or hosted gateway account. This notice covers the GPROXY application, not the separate services you choose to connect.

Information the application handles
When you configure and use the gateway, it processes provider accounts and API credentials, gateway users and access keys, requests and responses, and operational records such as usage, quotas, errors and timing. Requests may contain personal information, prompts, images, audio, files or other content supplied by you or clients connected to the gateway. Do not send information you are not entitled to share.

Storage and retention
Configuration, credentials and records are kept in the database and storage locations you select. Request logging and retention depend on your settings. A remote database or storage service you configure is not local-only storage. The application reports whether credential encryption is available; do not assume all stored credentials are encrypted. Protect the device, database, backups and keys.

Network transfers and third parties
Requests and the necessary credentials are sent to the provider and endpoint you configure, including outside your country if you choose such a service. Provider sign-in, model lists, quota queries, model resource downloads and remote database connections also contact the corresponding services. Those services apply their own terms, retention rules and privacy policies. Configure them only if you agree to their processing.

Interface fonts are bundled with the application and do not require downloads from external services. If a font is unavailable, the interface uses system fonts. Store-installed copies receive application updates from the store, under that store's policies. GPROXY does not automatically send gateway data to the publisher, including for analytics or support.

Permissions
Internet access enables the gateway and configured network services. Android notifications and foreground service permissions keep a gateway that you start, or allow to start at boot, visible and provide a Stop action. On Android, optional startup and battery settings let the gateway continue when you leave the app; you can change them in application or system settings. HarmonyOS background operation depends on the device and permissions actually granted. Store copies do not request permission to install downloaded APKs.

Your choices and deletion
You choose the providers, endpoints, storage, clients, logging and retention. The listener defaults to the local device; exposing it to a network changes who can reach it. Other apps on this device can connect to the local listener, but model API requests still require a gateway access key. Keep those keys private. Remove configured accounts, credentials and records through the management interface where supported. Stop the gateway before deleting all instance data. Clearing Android application storage or uninstalling removes its private local data; separately remove exports, backups, remote databases and provider-side records. HarmonyOS application data can be removed through system application/storage settings; remove any separately saved backups as well. Deleting local data does not delete a provider's copies. You can stop using the application, remove its data and uninstall it at any time.
